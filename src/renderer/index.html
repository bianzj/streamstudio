基本几何

几何体表面

生成封闭外壳，适用于建筑等连续表面。立方体按六个面细分，椭球生成连续三角网格。

几何体混沌

仅在包络内部生成离散三角面元，不输出封闭外表面；适用于树冠等混沌介质。

水体位置与偏移

最终位置为中心位置加整体偏移；生成后仍可在对象“分布”中修改。

参与介质辐射参数

坐标统一为 X 南北、Y 向上、Z 东西；参与介质会衰减、散射并按固定温度发射。

物化属性

Mesh 属性映射

Mesh光谱温度物化属性结构属性Mesh 镜面反射
镜面反射逐 Mesh 独立设置，共用同一属性不会联动；仅简单光线追踪的短波计算生效。OBJ 定义三维形状，各 Mesh 的物化属性决定能量过程。光伏热电耦合使用 FacetEB，并需绑定不透明光谱。
OBJ 方向统一为 +X 北、−X 南、+Y 上、+Z 东、−Z 西；Three.js 与计算引擎保持一致。MTL 不参与计算。
OBJ Properties

编辑 OBJ 计算属性

对象属性绑定

体元模式：OBJ 面元就是真实叶片时选“按 OBJ 面元面积计算”，每个体元的叶面积密度 = 体元内面元面积 / 体元体积，树冠边缘部分填充的体元不会被高估；OBJ 只是树冠外壳等代理几何时保持默认。面元模式和光线追踪模式直接使用面元，不受此项影响。

Mesh 完整属性映射

Mesh光谱属性温度属性物化属性结构属性Mesh 镜面反射
镜面反射逐 Mesh 独立设置，共用同一光谱或物化属性不会联动；仅简单光线追踪的短波计算生效。粗糙度越小，高光越集中。修改对象物化属性会同步到全部 Mesh，也可逐行独立设置。光伏热电耦合使用 FacetEB 和不透明光谱。
选项来自“材质属性”预设库；保存后更新 project.json。
