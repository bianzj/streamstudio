# 面元比例收敛判据（2026-11-02）

按用户要求，外层只采用一个条件：能量残差绝对值 ≥2 W/m² 的面元数 / 总面元数 <0.001。等于 2 W/m² 算未达标，等于 0.1% 不收敛。按面元数量而非面积计数；一个面元取两个求解状态及独立两侧的最大绝对残差，只计一次，避免符号抵消和重复计数。对象的整体通量本来在两侧重复，只使用一侧。

CPU/GPU 的迭代退出和最终 converged 标记均使用同一个比例条件。温度变化、等效温差、最大叶片残差、气孔残差和 MOST 稳定度均只保留诊断值，不再增加收敛门槛。无效/非有限输入仍作为计算错误处理，不是额外收敛指标。

内部气孔阈值 0.01、最多 24 次；温度阈值 0.01 K、最多 32 次，保持上一轮用户指定设置。整数比较 failingFacets*1000<totalFacets 使用 64 位乘法，防止比例边界舍入和溢出。

- histream 和 histream_runtime_resources 构建成功，仍有原有 MSB8028 警告。
- 定向 C++ 测试通过：±2 W/m² 严格边界、0.1% 严格边界、零面元、141152 面元允许 141 个但不允许 142 个未达标，以及大计数乘法。
- 内层预算和提前退出测试通过。
- 原始 144 株玉米全场 141152 面元、24 个时刻、外层上限 100、松弛系数 0.25：24/24 按新判据收敛，耗时 63.758 秒，外层合计 444 轮。
- 各时刻最大未达标面元数 135，最大未达标占比 0.095642%。正午未达标 133/141152，占比 0.094225%。
- 每个 GPU 节点最终通量回读后，用 CPU 对同一份 GPU 通量重新计数，全部与 GPU 整数归约结果一致。这是计数一致性验证，不是两套生理方程逐轮严格数值一致性的声明。
- 独立 CPU 能量路径：单株真实玉米加地面共 4158 面元，两个正午相邻节点均按新比例判据收敛；温度变化大于旧 0.05 K 门槛仍可通过，确认旧条件不再参与判定。
