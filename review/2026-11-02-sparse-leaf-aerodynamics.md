# 稀疏边缘面元高温修正

## 原因和实现

原代码把冠层整体、按单位地表面积定义的边界层阻力 `rbc=70/LAI*sqrt(w/u)` 放入每单位叶面积的面元通量计算，并与公共空气路径一起乘以 `(LAI+1)`。当1m网格只有伸出的一小片叶时，局部LAI约0.018–0.019，出现约2300–2600 s/m的叶片阻力。另一处问题是 `LAI<=0.01` 时，叶片和土壤一起切换到裸土阻力。

[SCOPE 官方 resistances.m](https://raw.githubusercontent.com/Christiaanvandertol/SCOPE/master/src/fluxes/resistances.m) 将 rbc 定义为冠层边界层阻力，并列出相应的70/LAI表达式。这里只核对公式与量纲，没有运行SCOPE对比。

面元 H、LE 按单面叶面积计，冠层与叶片边界阻力满足 `r_boundary_leaf=LAI*rbc`。因此改为：

```
r_boundary_leaf = 70 * sqrt(leafWidth / windAtCanopySource)
r_leaf = (LAI + 1) * r_common_air + r_boundary_leaf
```

保留已有公共空气路径的等效近似，只把叶片边界分支的面积口径改正；没有调高LAI、设置阻力上限或截断温度。有正叶面积的稀疏列继续计算叶片交换，不再套用裸土分支；土壤的原有阈值、阻力和稳定度参数保持不变。位移高度改用expm1计算以保证极稀疏正LAI的数值精度。空气动力参数在CPU统一生成并传给GPU，因此该物理改动不需要另写GPU阻力公式。

同时复现并修正温度内部提前退出的跳变：残余修正略低于0.01 K时直接返回旧值，略高于0.01 K时却应用修正。现在退出前应用已经算好的小修正，不增加求值或迭代次数。CPU与GPU同步修改。外层能量判据、rs阈值0.01、温度阈值0.01 K和24/32迭代上限不变。
