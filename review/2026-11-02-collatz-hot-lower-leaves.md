# 下层玉米高温：已修正的生理闭合错误与剩余边缘高温

## 已复现并修正的错误

当前面元 Collatz 路径原先用 g0=0 的解析式计算 Ci，再根据 A(Ci) 得到扩散导度，最后并联非零 g0。这不能同时满足光合作用、气孔导度与 CO2 扩散。面元 62764 在旧输出中使用 Ci=38 ppm，而加上 g0 后的导度按原换算反推 Ci 约78.54 ppm。原来约41.18℃的温度虽满足能量残差阈值，不能证明生理方程正确。

另一个错误是 A 相关导度用固定标准摩尔密度 1.2047/0.02896，g0 却用当前 RT/P 转换，混合了两种单位换算条件。

CPU facetrtcore.cpp 与 GPU energy_math.glsl 现同步求解：

```
gs = max(g0, g0 + m*A(Ci)*RH/Cs)          # mol H2O m^-2 s^-1
Ci = max(Ci_min, Cs - 1.6*A(Ci)/gs)      # ppm
gv = gs * R*T/P                          # m s^-1，P 为 Pa
rs = 1/gv
```

Ci_min 保护沿用原 C3 0.3Cs / C4 0.1Cs；保护起作用时用相应的扩散导度下界保持一致。g0 不再重复添加。夜间或非正净同化时保留 g0；g0=0 使用解析式。非零 g0 的 Ci 求解最多24次，Ci 精度0.01 ppm。该求解不同于已有 rs 搜索，原 rs 对数阈值0.01、最多24次和温度0.01 K、最多32次均不变。

非零截距需要耦合 Ci 的依据是 [SCOPE 官方 biochemical.m](https://raw.githubusercontent.com/Christiaanvandertol/SCOPE/master/src/fluxes/biochemical.m) 的 BallBerry/Ci_next 定义；仅查阅公式，没有运行 SCOPE 对比。原场景 Tcor=0、kV=0.7、Vcmax=60、m=4、g0=0.01、气象与辐射配置未调参。此次只改面元 Collatz 路径；Farquhar 与体元路径未改。

## 尚未解决的另一类高温

全场最高温仍53.716℃，不能宣称全部高温消除。30个面元超过45℃，都在0.75m以上，占总叶面积0.01825%。最高温面元56962位于边缘列[17,8]：列LAI仅0.01936、空气动力阻力2283 s/m、H=11.64、LE=97.47、能量残差0.534 W/m²。相邻类型的边缘列LAI约0.018，阻力可达2557 s/m。

代码按1m网格把三角形面积归入质心所在列，再将该列LAI用于 rbc=70/LAI*sqrt(width/u) 的冠层平均公式。边缘少量伸出叶片会产生极小列LAI及很大的交换阻力；中心62764所在列LAI=1.25774、阻力161.47 s/m。已定位剩余热点与该稀疏列参数化直接相关，但此次没有擅自更换空气动力学模型、抬高LAI或截断叶温。其物理适用性与网格依赖仍需单独处理。
