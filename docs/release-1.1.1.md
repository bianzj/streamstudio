# StreamSim 1.1.1

- VoxelEB 土壤方法 2 使用非均匀有限体积导热，地表通量包含表层储热和向下传导；固定底温传导计入守恒检查。热容量、导热率、饱和含水量及含水量使用对应材质参数，温度导数来自同一线性系统。
- Farquhar 生化计算按植被、土壤、建筑和水体分支访问各自参数；非植被碳通量为零，雾和火等参与介质跳过生化计算。
- VoxelRT 和 VoxelEB 漫射计算移除非一致工作组屏障。VoxelRT 不透明表面包含自身长波热发射，水体使用当前命中对象的参数。
- FacetEB 在每个节点保存温度增量、能量残差、残差对应温差和 `converged`。只有两项温差都达到配置容差才完成；耗尽迭代预算返回退出码 2，并保留结果。原生命令行索引为 `faceteb_run.json`。
- 网页和桌面服务的新运行保存到配置输出目录的 `runs/<runId>`。工程输入、生成的裁切几何及位置文件、气象快照和源文件/引擎/构建哈希保存在该目录；源工程输出设置及历史结果保留。停止、失败和未收敛分别记录状态。
- 同一 TIFF 的统计重新导出时替换对应记录。结果列表支持独立运行目录，界面保持本轮实际输出路径。
- VoxelRT 可见光/近红外过程字段使用 `illumination_<波长>`、无量纲单位 `1`；长波字段保留光谱辐亮度单位。二进制布局保持兼容，旧 `radiosity_<波长>` 名称作为别名。
- 构建部署目录包含 `build-manifest.json`，记录版本、实际引擎、源码和 SPIR-V 的 SHA256。共享 shader include 修改会触发重新编译，shader-only 构建也会部署资源。

数值回归验证不等于实测精度验证。应用案例的长期结果需要使用本版重新计算后再评估。
