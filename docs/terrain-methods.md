# 地形处理方案（Terrain methods）

## 分辨率原则

我们手里有 **30 m 或 10 m DEM**。在处理的 **1 km 或 2 km** 像元内，这个精细 DEM **足以解析像元内部的地形结构**；地形方案的区别，就是“像元内部结构怎么用”。

## 四种方法

### 1. 单一坡（single）

**一个像元一个坡度、一个坡向**，不是全图一个坡度。

- 每个像元一个平面（slope/aspect 可以是常数，也可以是栅格）；
- 像元内部不再区分更细的面元；
- 适合“像元尺度上只有一个主坡面”的近似。

配置：

```json
"terrain": { "mode": "single", "slope": 12.4, "aspect": 294 }
```

或逐像元栅格：

```json
"terrain": {
  "mode": "single",
  "slope":  { "file": "inputs/slope_1km.tif" },
  "aspect": { "file": "inputs/aspect_1km.tif" }
}
```

### 2. 面元法（facet）

**像元内如果有更精细的面元，就把更精细的面元逐个做**。

- 用 30 m / 10 m DEM 在 1 km / 2 km 像元内切出细面元；
- 每个细面元有自己的坡度、坡向，逐个算短波、长波、能量平衡和热红外；
- 再把细面元的结果聚合到 1 km / 2 km 像元；
- DEM 越细，面元越细；这是“用真实地形面元逐个解析”的方法。

实现上：在 30 m / 10 m 网格上运行 STREAM（每个细像元就是一个面元），再按目标像元聚合。若直接在 1 km / 2 km 网格上跑 `facet`，每个像元只有一个 DEM 面元，是面元法的退化情形。

### 3. 山包复合坡（hill）

**像元内认为是有几何体分布**：圆锥山包 + 密度。

- 参数：山包坡度 β、覆盖率密度 d（0–1）；
- 像元内 12 个方位面元（30° 间隔），每个面积权重 `d/12`；平坦部分 `1−d`；
- 短波按面元局地太阳入射加权；热红外按面元局地视角 + Hapke + 投影面积加权；
- 这是**几何体统计分布**，不是真实 DEM 面元。

配置：

```json
"terrain": {
  "mode": "hill",
  "slope":   { "file": "inputs/hill_slope.tif" },
  "density": { "file": "inputs/hill_density.tif" }
}
```

### 4. 山脊复合坡（ridge）

**默认无限长山脊**：沿走向无限延伸的三角棱柱，两个坡面，没有端面。

- 参数：山脊两坡坡度 β、走向（strike）、覆盖率 d；
- 两个坡面：朝 `strike ± 90°`，坡度 β，各占 `d/2`；平坦部分 `1−d`；
- 短波/热红外按两个坡面 + 平坦部分加权；
- 形状由坡度 β 和覆盖率 d 描述；**长度默认无限，不设端面**。

配置：

```json
"terrain": {
  "mode": "ridge",
  "slope":   { "file": "inputs/ridge_slope.tif" },
  "aspect":  { "file": "inputs/ridge_strike.tif" },
  "density": { "file": "inputs/ridge_density.tif" }
}
```

可选的 `endFraction`（端面比例）默认 **0**，即无限长；只有明确要模拟短山脊/孤立小山脊时才设大于 0，标准山脊不要用。

## 区别一句话

| 方法 | 像元内部结构 |
| --- | --- |
| 单一坡 | 一个平面（每像元一个 β、φ） |
| 面元法 | 真实细 DEM 面元，逐个算，再聚合 |
| 山包复合坡 | 圆锥几何体 + 密度（统计分布） |
| 山脊复合坡 | 无限长山脊两坡 + 走向 + 密度（统计分布） |

- **单一坡 vs 面元法**：单一坡是“一个像元一个平面”；面元法是“像元内细面元逐个做”；
- **面元法 vs 山包/山脊**：面元法用**真实 DEM 面元**；山包/山脊用**理想几何体 + 密度**，不依赖每个细面元的真实位置。

## 实现状态

- `single`：支持常数或坡度/坡向栅格，逐像元一个平面；
- `facet`：在 DEM 网格上逐像元一个面元；细面元版本是“30 m/10 m 跑 + 聚合到 1 km/2 km”；
- `hill`：12 方位面元 + 密度 + 平坦，短波和热红外都按面元加权；
- `ridge`：两坡面 + 走向 + 密度 + 平坦，同样按面元加权；
- 四种方法共用同一套高程订正、4 组分温度和热红外方向发射率。

## 与 TiRT 的关系

- TiRT 的复合地形是“圆锥高度/半径/密度 + 12 方位面 + 4 共享温度 + 面间交换”；
- 本方案的 `hill` 与 TiRT 的几何体分布同一思路，但当前是**4 共享温度、无面间长波交换**；
- `facet` 是 TiRT 没有的“真实细 DEM 面元逐个算”的路线；
- `ridge` 是山脊几何体分布，TiRT 没有对应分支。
