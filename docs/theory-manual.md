## 0. 本版方法总览与证据边界

### 0.1 两种空间表达、两套原生引擎

Stream Studio 统一提供三维场景和区域遥感影像两类工作台。三维工作台调用 HiStream（`histream.exe`），以 OBJ、面元或体元表达真实结构；遥感工作台调用 STREAM（`stream.exe`），以对齐的栅格、地类、LAI、地形与四组分温度表达像元。两者共享研究问题和部分物理概念，但离散尺度、参数含义及边界条件不同，不应把同名量视为自动数值等价。

| 方法链 | 主要输入 | 计算过程 | 主要输出 |
|---|---|---|---|
| 三维 RT | 几何、材质、给定温度、太阳与观测方向 | 可见性、遮挡、散射、热辐射 | 反射率、辐亮度、亮温 |
| 三维 EB | 三维 RT 输入与气象、热物理和生理参数 | 辐射与能量平衡耦合 | 结构单元温度、通量、合成影像 |
| 遥感 RT | DEM、地类、LAI、组分温度、观测几何 | 冠层及土壤方向辐射算子 | 冠层顶光学与热红外影像 |
| 遥感 EB | 栅格属性与 ERA5 等气象驱动 | 组分能量平衡与正向成像 | 组分温度、能量通量、影像和质量信息 |
| 遥感同化 | RT/EB 背景与温度或反射率观测 | 可微观测算子与 MAP 分析 | 分析场、不确定度、残差和质量标记 |

RT 是给定状态后的辐射映射；EB 才求解物理温度。亮温由辐射经逆 Planck 换算，地表温度还依赖发射率约定，四组分物理温度描述不同受光状态，三者不能互换。冠层顶辐射与大气顶层观测也须分别处理。

### 0.2 遥感像元的计算方法

遥感模式首先核对 DEM、地类、LAI、温度及气象的投影、范围、网格和缺测标记。RT 使用外部给定的光照土壤、阴影土壤、光照叶片及阴影叶片温度；EB 根据短长波辐射、气温、湿度、风和土壤条件求解各组分收支，并输出显热、潜热和土壤热通量。四组分权重、冠层多次散射、叶片/土壤光谱、方向发射率及地形几何共同进入成像链。参数默认值与具体选项应以工程 JSON 和本次运行摘要为准。

同化以观测算子连接控制变量与亮温、地表温度、组分温度或反射率。RT 主要更新组分温度；EB 主要更新土壤水分和 Vcmax；提供光学观测时还可更新 LAI。求导、MAP 目标、后验协方差及信息量定义详见 15.6 节。单角度观测对四组分通常欠约束，低观测残差不意味着四个温度都准确。

可直接追溯的实现入口为 `models/stream/app/assimilation.cpp`、`models/stream/app/inversion.cpp`、`models/stream` 下的辐射与能量模块、`models/histream/src` 与 `models/histream/shader`。应用工程迁移与字段映射由 `server/stream/config.mjs` 和 `src/renderer/src/project-unified.js` 承担。源码位置用于核对实现，不能替代物理验证。

**STREAM EB 当前数值方法。** 默认 robust 温度步采用 0.8 阻尼牛顿，单步限制为 5 K，温度保护范围为 240-380 K。Monin-Obukhov 稳定度以 `1/L` 为变量，按 0.5 松弛更新，浮力目标只含显热。迭代中的稳定度容差为 `1e-4 + 0.02|target|` m⁻¹；提前退出还要求最大组分能量残差不超过 0.5 W m⁻²、阵风显热残差不超过 1 W m⁻²。返回前重新评估，最终 QA 的对应阈值为 5 W m⁻²、2 W m⁻²与两倍稳定度容差。因此 QA 收敛不意味着达到任意更严格的残差阈值。极寒地表可能触及 240 K 保护下限，需单独评估适用性。这些参数描述 STREAM 的当前实现，不代替 HiStream 的独立数值控制。

**STREAM 2026-11-20 修正。** 以下各项改变正向结果，反演与同化使用同一算子：

- 热红外亮温补反射天空项：L = Σ w_k B(T_k) + (1 − Σw)·B(T_sky)，T_sky = (L↓/σ)^¼。L↓ 由 `skyLongwave` 决定：auto 时 EB 取过境时刻 ERA5 `strd`，RT 取 Swinbank 晴空式 5.31×10⁻¹³ T⁶（T 取阴影叶温，无叶时取阴影/光照土壤温度；只做 LST 反演且无组分温度时取观测亮温均值）；也可给常数或栅格，`{"mode":"none"}` 为旧行为。LST 产品观测（Σ w_k B(T_k)/ε）不加天空项。宽带 L↓ 折成黑体天空温度会略高估 8–13 μm 窗区天空辐亮度，ε≈0.97 时约 0.1–0.2 K。
- 太阳天顶角 ≥ 90°（含局地坡面背光）时没有光照组分，光照土壤/叶片权重并入阴影组分，Σw 不变。
- 地形短波：先在水平面按直散比分配并做晴空 DNI 限幅（真实太阳天顶角），再把直射乘 cos i / cos θs、漫射乘天空视角因子投影到坡面；能量平衡用局地入射角 i 计算冠层直射消光与光照比例。平地不变；`eb_forcing.tif` 的短波仍为水平值。单坡地形的热红外成像也改用坡面几何。
- BSM 湿土采用 SCOPE soilwat：k = 0…6 层水膜按 Poisson 权重混合，水膜透过率按双程 tw = exp(−2 k_w·film·k) 计。
- 地类 0、16 无光合、无气孔，16 的叶片结构参数 N = 1.5（PROSPECT 要求 N ≥ 1）；水体（17）按水面地面处理，不建 Hapke 表，发射率不随含水量变化。
- 冠层上方阻抗 rar 的稳定度项移入 1/(κu*) 括号内（见 7.2 节），与 TIRTEB 有意不同；中性层结无差别。

## 1. 模型定位

Stream Studio 是面向三维地表场景的光学—热红外辐射传输与能量平衡正向模型。模型把几何结构、光谱属性、组分温度、太阳—天空条件、观测方向和大气状态放入同一计算链，输出传感器可观测的辐亮度、反射率或亮度温度。

当前提供五种计算模式：

| 模式 | 空间表达 | 核心求解 | 主要结果 |
|---|---|---|---|
| FacetRT | 三角面元 | 可见性栅格与辐射度迭代 | 光学/热红外图像 |
| VoxelRT | 体元 | 沿线消光与多次散射 | 光学/热红外图像 |
| FacetEB | 三角面元 | FacetRT 与能量平衡耦合 | 面元温度及时间序列图像 |
| VoxelEB（`eVoxelEB`） | 体元 | VoxelRT 与能量平衡耦合 | 体元温度、GPP/NPP 及时间序列图像 |
| RayTracing | 三角面元 | 后向光线追踪 | 独立成像对照结果 |

这些模式共享场景、材质、气象、传感器和输出定义，但数值离散不同，因此结果不应被理解为逐像元完全相同。Facet 模式保留表面几何，Voxel 模式把结构等效到有限体积中；两者的差异本身可用于评估尺度效应与结构简化误差。

当前新建工程默认使用 `eVoxelEB`，界面简写为“体元能量平衡 / VoxelEB”；默认土壤温度方法为 `soilTemperatureMethod = 2`，即温度廓线传导模型。工程配置以 `schemaVersion = 6` 保存。

Stream Studio 1.1 的重点工作是异质性体元：在不把原始三角面长期保留到每次射线查询中的前提下，把亚体元密度、三轴方向遮挡和主要类别混合信息压缩为紧凑体元描述符。它连接了“真实 OBJ 几何”与“高效 VoxelRT/VoxelEB”两种尺度，是森林、作物和城市混合场景保持结构方向性的核心途径。

## 2. 场景表达与坐标体系

### 2.1 坐标与计算域

用户侧与当前计算引擎统一采用右手坐标：`+X` 指向北、`-X` 指向南，`+Y` 垂直向上，`+Z` 指向东、`-Z` 指向西。太阳与视场方位角以北为 `0°`、东为 `90°`。平行投影以地理北向作为影像上方；中心投影在倾斜观测时将世界竖直方向投影到像平面作为相机上方，使地平线保持水平，在正下视退化位置再使用地理北向。计算域由南北长度 `L_NS`、最大高度 `H` 和东西长度 `L_EW` 定义。

Facet 模式直接使用三角形位置、法向、面积和材质编号。Voxel 模式将计算域划分为：

```text
Nx = ceil(L_NS / d)
Ny = ceil(H / d)
Nz = ceil(L_EW / d)
```

其中 `d` 为体元大小。体元越小，几何细节越高，但体元数近似按 `d^-3` 增长。输出图像分辨率只控制传感器采样，不等于体元分辨率，也不等于 FacetRT 内部可见性栅格。

局部计算域采用轴对齐包围盒及 X/Y/Z 偏移表达。显示场景与计算场景分离：Three.js 仍显示原始完整背景，而运行时先做对象包围盒判定；完全域外对象跳过，跨界对象裁切到域内。对于单实例 OBJ，三角面在体元化前进行几何裁切，因此跨边界对象的域外部分既不生成体元，也不参与后续辐射和能量求解。局部坐标由原世界坐标减去计算域原点得到，材质与物理属性保持不变。

### 2.2 地物属性分层

几何对象通过四类属性进入求解：

- 光谱属性：波长相关的反射率 `rho_lambda`、透射率 `tau_lambda` 和吸收率；
- 温度属性：阳面、阴面或时间更新后的物理温度；
- 结构属性：刚体、混沌介质、火焰、雾等结构类型及密度参数；
- 物化属性：植被生理、土壤热物理、水体混合层等参数。

对任意非发光材料，能量约束为：

```text
alpha_lambda = 1 - rho_lambda - tau_lambda
0 <= rho_lambda, tau_lambda, alpha_lambda <= 1
```

热平衡条件下依据 Kirchhoff 定律，可取方向—波长发射率等于同方向—波长吸收率。对于不透明表面 `tau_lambda = 0`，因此 `epsilon_lambda = 1 - rho_lambda`。

土壤热红外的 `rho_lambda` 随体积含水量变化：孔隙被水填充后表面光学上更平滑，反射率下降、发射率升高。BSM 光谱材质因此用干端和湿端两个 TIR 反射率插值，权重与 BSM 反射率共用同一含水量几何：

```text
SMC   = clamp(SMC, 0, 1)                       # 体积分数；>1 按百分比换算
mu    = max(SMC - 0.05, 0) / 0.25              # 与 BSM 相同的干端阈值与尺度
w     = 1 - exp(-mu)                           # 0 为干端，趋近 1 为饱和
rho_TIR = rho_dry + (rho_wet - rho_dry) * w
epsilon_TIR = 1 - rho_TIR - tau_TIR
```

`rho_dry` 即材质面板的“TIR 反射率”，`rho_wet` 的缺省值是干端发射率 `+0.03`（上限 0.995），可用“湿端 TIR 反射率”覆盖；湿度只降低 TIR 反射率，所以发射率随含水量单调不减。遥感影像引擎用同一组常数，把地类半球发射率从干端值插值到饱和值（`energy.soilEmissivityWet` 可指定饱和发射率）。叶片、混凝土和导入波谱等非 BSM 材质不随含水量变化。

### 2.3 配置与运行数据链

三维工作台的正式运行链为：

```text
GUI -> project.json -> Node 本地服务 -> histream.exe
```

遥感工作台使用 `project.json -> Node 配置规范化 -> stream.exe`，运行配置保留输入路径、像元模式和输出目录。下文第 2 至 13 章主要描述 HiStream；区域遥感同化及温度反演重点见第 15 章。

## 3. 光学与热红外共同辐射方程

### 3.1 光学波段

太阳短波到达场景后分为直射和天空漫射。传感器方向上的离地辐亮度可概括为：

```text
L_surface(lambda, omega_v)
  = L_direct + L_diffuse + L_multiple
```

其中直射项受太阳可见性、入射角和地物方向反射控制；漫射项来自天空半球；多次散射项来自其他面元或体元。模型不是仅做阴影着色，而是在有限追踪深度或辐射度迭代内传递波段能量。

若输出反射率，可用给定太阳—天空辐照度对离地辐亮度归一化。传感器波段值应严格写成波段响应函数 `S_b(lambda)` 下的积分：

```text
L_b = integral[L_lambda S_b(lambda) d lambda]
      / integral[S_b(lambda) d lambda]
```

当前自定义波长在缺少完整响应函数时按离散中心波长计算，不应把单波长值误认为真实宽波段响应的严格积分。

### 3.2 热红外波段

温度为 `T` 的黑体单色辐亮度由 Planck 定律给出：

$$
B_\lambda(T)=\frac{2hc^2}{\lambda^5}
\left[\exp\left(\frac{hc}{\lambda kT}\right)-1\right]^{-1}.
$$

对于异质冠层，Bian et al.（2025）给出的冠层顶部热红外辐亮度原式为：

$$
L(\theta_s,\theta_v,\phi)
=\sum_j\left[\varepsilon_j f_j(\theta_s,\theta_v,\phi)
+\varepsilon_{m,j}\right]B_\lambda(T_j)+r_cL_a^\downarrow .
\tag{R10-1}
$$

其中，$f_j$ 是传感器方向上组分 $j$ 的可见比例，$\varepsilon_{m,j}$ 是多次散射形成的附加有效发射率，$r_c$ 是冠层半球—方向反射率，$L_a^\downarrow$ 是大气下行有效辐亮度。该式清楚分开了组分自身发射、多次散射和天空下行辐射反射。STREAM 遥感引擎自 2026-11-20 起按 Kirchhoff 关系取 $r_c=1-\sum_j w_j$（$w_j$ 为方向有效发射率权重），$L_a^\downarrow$ 用宽带下行长波折成的黑体天空辐亮度，见 0.2 节。

模型先求辐亮度，再通过 Planck 反函数得到亮度温度。亮度温度是传感器辐射量对应的等效温度，不一定等于某个面元或体元的物理温度。一个像元包含多个温度组分时，必须先按辐亮度混合，不能直接线性平均温度。

### 3.3 大气顶层观测

启用大气后，地表到传感器的简化观测方程为：

```text
L_TOA(lambda) = transmittance(lambda) * L_surface(lambda)
                + L_path(lambda)
```

热红外图像的处理顺序是：物理温度转为辐亮度、进行大气传播、再反演为传感器亮度温度。大气透过率和程辐射都随波长、柱状水汽、气溶胶负荷、路径高度和观测角变化。

## 4. FacetRT 面元辐射传输

### 4.1 面元与可见性

FacetRT 将 OBJ、DEM 和参数化几何离散成三角面元。每个面元保存位置、法向、面积、正反面关系和材质属性。太阳直射与面元之间的辐射交换首先依赖几何可见性：

```text
V_ij = 1  面元 i 与 j 互相可见
V_ij = 0  被其他几何遮挡
```

当前实现通过 Vulkan 栅格化建立可见性/阴影记录。重叠几何沿同一栅格像元形成 A-buffer 深度链：默认 64 个片元层；场景边长 ≥ 1000 m 时可见性栅格加倍、起始层数降为 16，再按全场平均片元深度自动倍增，最多回到 64。全场平均深度看不到局部稠密冠层，因此溢出时不再报错中止：GPU 端把层数加倍（128、256）并重建可见性资源，同时重建依赖它的求解资源；单方向太阳可见性溢出时也会重建可见性图后重试，已算出的物理量不受影响。加倍受三重限制——着色器上限 256 层、`maxStorageBufferRange`、以及设备本地显存最大的 25%（可用 `HISTREAM_FACET_RASTER_BUDGET_MB` 覆盖），超过后报错。环境变量 `HISTREAM_FACET_RASTER_LAYERS` 仍可指定起始层数 64/128/256。保留的 CPU 光栅后端在溢出时会加倍层数并重跑该阶段，上限 128 层或 2 GiB 片元缓冲。输出图像分辨率独立设置。

### 4.2 形状因子与辐射度

TRGM-EB 的面元辐射度原式为：

$$
B_i=E_i+x_i\sum_jF_{i,j}B_j,
\qquad i,j=1,2,\ldots,2n_p .
\tag{R1-1}
$$

其中，$B_i$ 为面元 $i$ 的辐射度，$E_i$ 为源项，$x_i$ 为反射率或透射率，$F_{i,j}$ 为从面元 $j$ 到面元 $i$ 的形状因子，$n_p$ 为双面面元数。面元源项原式为：

$$
E_i=
\begin{cases}
[F_s(i)+F_d(i)]\rho_i+[F_s(i+n_p)+F_d(i+n_p)]\tau_i+F_e(i), & i\le n_p,\\
[F_s(i)+F_d(i)]\rho_i+[F_s(i-n_p)+F_d(i-n_p)]\tau_i+F_e(i), & i>n_p.
\end{cases}
\tag{R1-2}
$$

直射、天空漫射和面元热发射分别为：

$$
F_s(i)=E_{sun}|\mathbf n_i\mathbf s_d|a(i,\theta_d),
\tag{R1-3}
$$

$$
F_d(i)=\sum_{k=1}^{N}I_{atm}(\theta_k)\frac{2\pi}{N}
|\mathbf n_i\mathbf s_k|a(i,\theta_k),
\tag{R1-4}
$$

$$
F_e(i)=\varepsilon_iB_\lambda(T_i).
\tag{R1-5}
$$

$a(i,\theta)$ 是相应方向的可见面积比例。形状因子由几何投影获得，满足互易关系 $A_iF_{i,j}=A_jF_{j,i}$；离散后，面元 $i$ 接收的半球辐照度由所有可见面元辐射度加权求和。

原论文的传感器方向合成式为：

$$
I(v)=
\frac{\sum_{i=1}^{2n_p}\dfrac{B_i}{\pi}
|\mathbf n_i\mathbf s_v|a(i,\theta_v)\operatorname{area}(i)}
{\sum_{i=1}^{2n_p}|\mathbf n_i\mathbf s_v|a(i,\theta_v)
\operatorname{area}(i)}.
\tag{R1-23}
$$

当前 Stream Studio 保持双面反射/透射关系，并用 Vulkan compute shader 的 Jacobi/松弛迭代替代论文中的串行 Gauss–Seidel 求解。FacetRT 光谱求解在达到残差阈值或最大迭代次数时结束。FacetEB 能量平衡内：短波窗口与传感器影像波段的 GPU 求解每 8 次迭代检查一次，变化量 ≤ 10⁻⁵ × 窗口辐照度时提前停止；耦合迭代中的长波 Jacobi 从上一轮解热启动、只做 16 次，其他求解改写了乒乓缓冲后回到冷启动（64 次）。长波 r+t 很小（约 0.03），热启动误差 < 10⁻³ W m⁻²；r+t 接近 1 的稠密冠层短波仍可能在最大迭代内未完全收敛。该过程适合漫反射主导的多次散射；强镜面材料需要专门的 BRDF 路径，不能简单等同于漫反射辐射度。

**周期边界下的可见性窗口。** 开启周期邻块时，几何按实例复制邻块，但每个可见性方向的正交投影窗口在 x/y 上只取中心块的外接球（所有方向半径相同，保持各方向在计数中的权重一致），深度方向仍覆盖全部副本，因此邻块只参与遮挡，不再稀释中心块的栅格分辨率（此前窗口包住全部副本，有效分辨率下降 9–25 倍，零样本面元按全天空处理，入射偏高）。GPU 与 CPU 后端一致。环境变量 `HISTREAM_FACET_RASTER_SIZE` 可提高栅格边长，用于生成参考解。

**输出范围。** 光谱反射率/HDRF 只剔除 NaN、Inf 与负值，不截断到 1；朝阳坡面、热点和镜面方向的 BRF > 1 是物理上正常的值。

**光照来源。** FacetRT 与 FacetEB 共用光照设置：Esun/Esky 文件各自只提供光谱形状，直射/漫射份额由 `directScatteringRatio` 决定（与 VoxelEB 相同）。直射由水平值换算为法向值时，太阳低于 cos θs = 10⁻⁴ 或法向值超过 1400 W/m² 封顶而丢弃的部分计入天空漫射，水平短波总量不变。FacetEB 的总量来自气象驱动；FacetRT 的光学输出已归一化，总量沿用历史值 700·cos θs + 50 W/m²，只取光谱形状和直散比；未给光照设置（OBJ 输入或 XML 无相关项）时仍为 700 W/m² 法向直射与 50 W/m² 天空。总量只影响 2.5–6 μm 热红外波段的太阳反射绝对量，可用光照设置 `light.shortwaveIrradiance`（W/m²，0 = 上述历史值）指定（见 5.2 节“中波红外太阳反射”）。

**材质能量分类。** 材质有 `surfaceEnergy` 块时按其设置；没有时按对象 `componentType`：Vegetation 为叶片（材质名含 wood 的木质部分除外），其他非空类型（Building、Water、Soil 等）为固体表面，无气孔与光合；旧 XML 无类型时，有 `leafBio` 块为叶片，有 `soilSet`/`waterSet` 块为固体，其余按叶片。

### 4.3 FacetRT 加速

传统模式逐波段构建源项并求解。加速模式保留每个波段的独立光谱属性和输出，只复用相邻同类型波段的初始辐射度，使迭代更快进入收敛区间。它不是把 500 个光谱简单压成 5 个光谱，也不以中间波段插值代替最终波段求解。

## 5. VoxelRT 体元辐射传输

### 5.1 沿线消光

VoxelRT 将复杂几何转成有限体元。Fan et al.（2025）的体元间透过率原式为：

$$
\tau_{i\rightarrow j}=\tau_i\tau_1\cdots\tau_m
=\prod_{k=0}^{m}\exp(-LAD_k\,G\,pl_k).
\tag{R7-12}
$$

其中，$m$ 为体元 $i$ 与 $j$ 之间经过的体元数，$LAD_k$ 为体元叶面积密度，$G$ 为单位叶面积在传播方向法平面上的平均投影，$pl_k$ 为射线在体元 $k$ 内的路径长度。当前异质性体元对原式扩展为：

$$
\tau_k(\boldsymbol\omega)=
\exp[-\rho_kG(\boldsymbol\omega)CI_k(\boldsymbol\omega)pl_k s_k].
\tag{当前实现式}
$$

这里的 $\rho$ 对应真实结构密度，$CI$ 是方向团聚修正，$s_k$ 是单位尺度换算项。$CI=1$ 且 $\rho=LAD$ 时退化为论文的 Beer–Lambert 原式。

该式给出射线不与内部介质发生相互作用的概率。被截获部分再依据 `rho_lambda`、`tau_lambda` 和 `alpha_lambda` 分配为反射、透射和吸收/热发射。因而 Voxel 方法可理解为沿离散路径估计方向交换概率，但它不是显式存储全部面元对形状因子的矩阵。

### 5.2 直射、漫射与传感器成像

Fan et al.（2025）首先把体元辐射度写为：

$$
B_i=E_i+\chi_i\sum_{j=1}^{2n_p}F_{i,j}B_j,
\qquad i=1,2,\ldots,2n_p,
\tag{R7-1}
$$

$$
E_i=F_{i,s}+F_{i,d}+F_{i,e}.
\tag{R7-2}
$$

直射与天空漫射项为：

$$
F_{i,s}=E_s\cos(\theta_s)\tau_{s\rightarrow i}P_i(\Omega_s),
\tag{R7-3}
$$

$$
F_{i,d}=\frac{1}{N/2}\sum_{k'=1}^{N/2}
E_{sky}\tau_{sky(\Omega_{k'})\rightarrow i}P_i(\Omega_{k'}).
\tag{R7-4}
$$

体元间形状因子为：

$$
F_{i,j}=\frac{\tau_{i\rightarrow j}(1-\tau_j)}{N}.
\tag{R7-11}
$$

体元的等效发射率和热发射源项由光谱不变量理论给出：

$$
F_{i,e}=\varepsilon_{i,voxel}\sigma T_{i,su}^{4}\tau_{s\rightarrow i}
+\varepsilon_{i,voxel}\sigma T_{i,sh}^{4}(1-\tau_{s\rightarrow i}),
\tag{R7-6}
$$

$$
\varepsilon_{i,voxel}=\frac{1-\omega_L}{1-p\omega_L},
\qquad
p=0.88\left(1-e^{-0.7LAI^{0.75}}\right).
\tag{R7-7}
$$

论文进一步给出体元散射项：

$$
\chi_i=\omega_{i,voxel}\Gamma_{i,\Omega_{k'}\rightarrow\Omega_k}
=\omega_{i,voxel}
\left(\rho_i\Gamma^-_{\Omega_{k'}\rightarrow\Omega_k}
+\tau_i\Gamma^+_{\Omega_{k'}\rightarrow\Omega_k}\right),
\tag{R7-8}
$$

$$
\omega_{i,voxel}=\frac{\omega_L-p\omega_L}{1-p\omega_L}.
\tag{R7-9}
$$

当前代码沿相同物理链计算太阳直射、天空漫射、体元间交换和传感器成像；数值实现针对 Vulkan 并行重新组织，不要求逐行复现论文的串行程序结构。

当前实现的几项约定（2026-11-20 修正）：

- **光学归一。** VoxelRT 光学输出为 HDRF：反射率 = πL / (E_dir·cos θs + E_diff)，E_dir 为法向直射，E_diff 为水平天空辐照（各向同性天空的 πL，与漫射追踪中每条天空射线携带的值相同，不再乘 0.5）；cos θs < 0.01 时不计直射。
- **接收面约定。** 植被体元存储两面合计（2/N 加权），各向同性散射按单面取 0.5；固体接收面（建筑、土壤、水体）只在存储外法线半球内积分并按余弦加权，存储值即辐照度，反射项直接为 BRDF 权重 × E，不再乘 0.5。VoxelRT 与 VoxelEB 一致；VoxelRT 建筑的太阳可见性也从法线所指的立方体面出发。
- **建筑体元法线与 OBJ 绕序无关。** 建筑面元的外法线由几何判定：同一 OBJ 中的建筑三角形按共享顶点分成闭合壳体，在面元中心前后各取一点，用竖直射线奇偶穿越判断哪一侧在实体外，法线指向外侧；两侧都在重叠实体内部时，近水平面朝上、其余保持原绕序。之后再按面积加权得到体元法线。绕序混乱的建筑资产（如 urban_block）因此不再出现屋顶法线朝下、屋顶自遮挡的问题，VoxelEB 建筑能量平衡也随之改变。
- **步数上限。** 达到追踪步数上限的射线视为未解析路径，保留已累积源项，不补天空；只有真实向上逃逸才计天空（VoxelRT 与 VoxelEB 一致）。
- **场景覆盖率（天空盒关闭时）。** 成像样本记录覆盖率 c = 1 − T_exit（T_exit 为射出场景或步数用尽时剩余的透过率），像元值取 Σ L_k / Σ c_k，即按覆盖率加权的平均；完全无覆盖的像元保持 0，由主机端填天空值。此前射出场景的样本被整体丢弃（RayTracing 按 0 计入），斜视或中心投影时冠层和物体边缘系统性偏暗。RayTracing 采用同一做法。
- **输出范围。** 反射率只剔除 NaN、Inf 与负值，不截断到 1（RayTracing、VoxelRT、VoxelEB 成像同样）。
- **按太阳方向缓存。** gap 与 diffuse 两个 pass 只取决于太阳方向；同一次运行中太阳方向不变的后续视角或航点只重跑成像 pass，结果逐位相同。
- **低太阳。** 太阳方向 cos θs ≤ 0.01 时 VoxelEB 不追踪直射，实测直射份额 Rin·direct 并入各向同性天空漫射，短波总量守恒；VoxelRT 光照由设置给定，此时直射不进入参考辐照度。
- **热红外波段。** VoxelRT 以 2.5 μm 为界（nm 或 μm 输入均可）：≤ 2.5 μm 为归一化光照的光学波段，> 2.5 μm 为绝对辐亮度（W m⁻² sr⁻¹ μm⁻¹）的热红外波段，计 Planck 发射与天空长波；扩散、成像与过程输出用同一判据。2.5–6 μm 的热红外波段另计太阳反射（见下条“中波红外太阳反射”），> 6 μm 不计。
- **中波红外太阳反射（2026-11-22）。** 3–5 μm 地表太阳光谱辐照度（约 5–10 W m⁻² μm⁻¹）与 300 K 发射（3.8 μm 约 0.5 W m⁻² sr⁻¹ μm⁻¹）同量级，此前不计使白天 MWIR 亮温偏低。现在 RayTracing、VoxelRT、VoxelEB 的热红外波段在发射之外加入太阳直射单次反射与天空散射短波反射，写法与光学分支相同（同一太阳可见性/gap 与 Kuusk 热点；植被用 Γ/G，固体用 BRDF 权重，水体用 Cox–Munk；RayTracing 在每个路径顶点做下一事件估计，VoxelRT 的直射与天空源进入扩散场，从而也计多次散射），只是光照为绝对值、结果累加为 L 而非 πL：
  - 光谱形状取自内置 `defined/Esun_.dat`（VoxelEB/FacetEB 短波光谱形状所用的同一文件）2500–6000 nm、100 nm 网格，除以其 400–2400 nm 积分（μm），得 $s(\lambda)$（μm⁻¹，3.8 μm 处 0.0113）；它已含 2.7、4.3 μm 吸收带，在 6.3 μm 水汽带降为 0，因此无需硬阈值；8–14 μm 窗区的太阳项小于发射的 0.1%，> 6 μm 不计，长波结果逐位不变。共享代码 `models/histream/shader/mwir_solar.glsl`。
  - 绝对量：VoxelEB 用该时刻实测短波 $R_{in}$，水平直射 $R_{in}\,f_{dir}\,s(\lambda)$、天空 $R_{in}(1-f_{dir})\,k\,s(\lambda)$，低太阳时直射并入天空（与光学分支一致）；RayTracing/VoxelRT 没有气象输入，水平短波总辐照 $E_g$ 优先取光照设置 `light.shortwaveIrradiance`（W m⁻²，> 0 时），未设置（0/空）时用 Haurwitz 晴空公式 $E_g=1098\cos\theta_s\,e^{-0.057/\cos\theta_s}$（θs=30° 约 890 W m⁻²），把各自的归一化光照（参考辐照度 direct·cosθs + diffuse，RayTracing 的天空项为 0.5·diffuse）按 $E_g$/参考辐照度放大；直射/天空份额始终跟随光照设置的直射比例，阴天设置（低总量、低直射比例）同时降低总量与直射份额，太阳在地平线下时为 0（2026-11-22 起；此前固定为晴空公式，阴天偏大）。静态 RT 模式只有太阳角而无对应时刻，不从气象文件取 $R_{in}$。$k=0.0847$ 为 Esky_/Esun_ 归一化形状在 2300–2400 nm 的比值，表示天空散射份额在 MWIR 不再随波长下降，是上界；Esky_ 在 2.5 μm 以外的数值是大气发射，已由天空温度表示，不重复计入。
  - 量级：θs=30°、ρ=0.1 的水平 Lambert 面在 3.8 μm 的太阳反射约 ρ·E·cosθs/π ≈ 0.1×7.8/π ≈ 0.25 W m⁻² sr⁻¹ μm⁻¹，约为 300 K 发射的一半，亮温升高约 10 K；受光叶片（ρ≈0.025）约 3 K。夜间（$R_{in}=0$ 或太阳在地平线下）该项恰为 0。
  - VoxelEB 的宽带长波传播与能量平衡不变（太阳能量已全部计入短波 $R_{in}$），太阳项只进入成像；VoxelEB 成像的 MWIR 太阳项只取单次散射（直射与天空各一次，与光学成像相同）。
  - FacetRT/FacetEB（2026-11-22）：热红外波段在 2.5–6 μm 同样计太阳反射，复用光学波段的面元光路——同一太阳受照比例 `sunlit`、直射项 sunlit·max(0, n·s)·E_b 进入辐射度求解（反射与透射、多次散射、天空视因子与光学波段相同），受照点/阴影点状态拆分也相同；只是辐照为绝对值并除以 π（热红外求解的单位为辐亮度 L）。直射 $E_b$ 与天空项加到 Planck 天空上：FacetEB 与 VoxelEB 同约定，水平直射 $R_{in}f_{dir}s(\lambda)$ 经同一水平→法向换算（低太阳/封顶丢弃部分并入天空），天空 $R_{in}(1-f_{dir})k\,s(\lambda)$，$f_{dir}$ 为能量平衡所用的直射份额；FacetRT 用其光照设置的直射/天空拆分，总量取 `light.shortwaveIrradiance`（> 0 时）或历史值 700·cosθs + 50 W m⁻²。面元的热红外反射率仍是 $1-\varepsilon-\tau$（地面含 Hapke 方向发射率、BSM 土壤随含水量），按朗伯面反射太阳，不另加光学波段的 Hapke 热点形状。GPU 常驻求解、CPU 审计（`HISTREAM_FACET_VALIDATE_SPECTRAL=1`）与 FacetEB 状态光谱用同一组数，> 6 μm 与夜间逐位不变；FacetEB 能量平衡不变，太阳项只进入影像/光谱输出。
- **热红外环境温度。** VoxelEB 图像中反射环境项的温度由入射长波反算：入射 = 存储吸收量 ÷ 吸收率（1 − r − t），植被再取单面一半，低发射率表面不再因只用吸收量而偏冷。
- **夜间跳过短波。** 太阳天顶角 ≥ 90° 且实测短波 ≤ 0.001 W m⁻² 时，该时间节点没有太阳直射也没有天空短波：实现先把太阳可见性与天空漫射比例（VoxelDir）、净辐射、PAR 和方向辐射场整体清零，再跳过可见性、直射与全部散射阶数，直接进入热红外传播与能量平衡。结果与逐条追踪完全一致（各源项在零辐照下恒为 0），散射诊断仍按节点写出（耗时为清零时间、各阶计数为 0），标准输出打印 `SHORTWAVE_SKIPPED`。晨昏时太阳仍在地平线上（天顶角 < 90°）即使短波很小也照常追踪。

**叶倾角分布、G 与 Γ 的自洽（2026-11-22 修正）。** 此前 VoxelRT/VoxelEB 的消光只用常数 $G$，叶片散射相函数 $\Gamma$ 固定为球形叶倾角的 Ross 闭式（隐含 $G=0.5$），Kuusk 热点式又写死 $G_{leaf}=0.5$；`LIDFa/LIDFb` 不参与计算。$G\neq0.5$ 时单次散射项 $\Gamma/G$ 被放大或缩小 $0.5/G$ 倍，能量不守恒。现在三者由同一叶倾角分布导出（共享代码 `models/histream/shader/lidf_common.h`，主机与 GPU 同源）：

- **叶倾角频率。** 主机端按 Verhoef 双参数 LIDF（SCOPE `leafangles`/PROSAIL `dladgen`）对 SAIL 13 个区间（中心 5°,15°,…,75°,81°,83°,85°,87°,89°）积分得频率 $f_i$（和为 1），连同漫射 64 方向上的 $G$ 表随冠层参数传入 GPU。
- **方向相关的 G。** $G(\boldsymbol\Omega)=\sum_i f_i\,\psi(\theta_{L,i},\mu)$，$\psi$ 为单一倾角类方位平均投影的闭式（$\cot\theta_L\cot\theta\ge1$ 时为 $\cos\theta_L\mu$，否则 $\tfrac{2}{\pi}[(\beta-\tfrac{\pi}{2})\cos\theta_L\mu+\sin\beta\sin\theta_L\sin\theta]$，$\cos\beta=-\cot\theta_L\cot\theta$），即 SAIL 的 $k_s\cos\theta_s$。任意 LIDF 在全球面上 $\langle G\rangle=1/2$。沿线消光 $\tau_k(\boldsymbol\omega)$ 中的 $G$、太阳可见性、视线截获 $(1-\tau)/G$、VoxelEB 直射投影 $G(\Omega_s)/\cos\theta_s$ 都用对应方向的 $G$。
- **Γ 与 G 同归一。** $\Gamma(\Omega'\!\to\!\Omega)=\rho\Gamma_R+\tau\Gamma_T$，$\Gamma_{R/T}$ 按倾角类用 SAIL `volscatt` 解析方位积分再按 $f_i$ 求和，满足 $\frac{1}{\pi}\int_{4\pi}\Gamma\,d\Omega=(\rho+\tau)G(\Omega')$，因此单次散射 $\Gamma/G$ 对任意 LIDF 能量守恒。球形分布的连续极限与 Ross 闭式 $\Gamma=\frac{\rho+\tau}{3\pi}(\sin\alpha-\alpha\cos\alpha)+\frac{\tau}{3}\cos\alpha$ 一致（误差 < 2×10⁻⁷）。
- **热点。** Kuusk 联合间隙率改为 $P=\exp[-\rho_L(G_s l_s+G_v l_v)+\rho_L\sqrt{G_sG_v l_s l_v}\,(1-e^{-a})/a]$，$G_s,G_v$ 与定义 $l_s,l_v$ 的消光同源；无相关时严格等于 $T_sT_v$。
- **漫射与多次散射。** 植被接收体对 64 个方向的入射权重由固定 $2/N$ 改为 $2G_i/\sum_j G_j$（各向同性场总量不变）；VoxelEB 多次散射核保留球形角形状，乘 $G(\Omega')/G(\Omega)$ 以保持对截获量的能量守恒（这是近似：漫射→漫射核未用精确 LIDF 形状），一次散射太阳源用精确 LIDF $\Gamma$ 并在离散方向上归一。
- **回退与球形极限。** 刚体、火焰/雾介质、`LIDFa = LIDFb = 0`（旧工程/预设表示未指定）以及超出 SAIL 定义域（$|a|+|b|>1$，引擎打印警告）时使用用户常数 $G$，$\Gamma$ 取球形形状并乘 $G/0.5$，保证 $\Gamma/G$ 守恒；`LIDFa > 1` 按 SCOPE 约定表示精确球形分布，$G=0.5$ 且使用原 Ross 闭式，结果与修正前一致（回归检验相对差 ≤ 5×10⁻⁷，仅浮点舍入）。默认 SAIL "球形" 参数 (−0.35, −0.15) 的 $G$ 在 0.490–0.505 之间随天顶角变化，因而默认工程有小幅数值变化。

数值检验见 `tools/test-lidf-gamma.cpp`：13 区间频率、闭式 $G$ 与暴力方位积分及独立 PROSAIL 双精度转写的对比（平面型 a=1,b=0、直立型 a=−1,b=0 等，误差 < 2×10⁻⁷）、$\langle G\rangle=1/2$、$\Gamma$ 归一（相对误差 < 2×10⁻⁵）、$\Gamma$ 与暴力积分及球形极限。

高光谱加速模式一次最多打包 4 个相邻波段，共享相同几何遍历；每个波段仍使用自己的光谱参数并产生独立结果，因此不引入波长插值误差。

### 5.3 均质体元与尺度意义

默认情况下每个体元被看成一种综合均质介质。减小体元可以表达更细的结构，但会提高体元数、射线步数和显存需求。增大体元时，必须由密度、方向结构因子和混合光谱保持亚体元结构的统计效应，否则会出现尺度依赖。

### 5.4 体元代理几何与求解边界

VoxelRT 和 Voxel RT–EB 会先读取 OBJ 三角面，并用这些三角面判断哪些体元被占据。每个有效体元随后创建三个相互正交的中面；每个中面由两个三角形组成，因此一个体元共有 6 个代理三角形，供 GPU 射线相交和路径遍历使用。

这些代理三角形不是完整六面立方体，也不会送入 FacetRT/FacetEB 作为表面面元求解。辐射量、温度和能量状态始终按体元存储并迭代。默认均质体元在完成体元化后不再依赖原始 OBJ 三角面；只有启用异质性体元时，才额外读取原始三角面，一次性统计叶面积密度、投影率和聚集指数等亚体元结构参数。

### 5.5 周期边界与天空边界

周期邻域通过沿射线遍历域副本实现，而不是复制几何。计算域在水平方向以 `Lx`、`Lz` 为周期重复（RayTracing 域为 `[-Lx/2, Lx/2] × [-Lz/2, Lz/2]`，体元模式以体元为单位，域为 `[-semi, N - semi]`，`N` 为水平体元数）。一条射线保持原起点和方向，按射线参数依次经过它所在的各个副本；对第 `(i, k)` 个副本，只在射线确实位于该副本内的参数区间 `[t_enter, t_exit]` 上查询加速结构，查询起点平移整数个周期：

```text
origin_query = origin - (i * Lx, 0, k * Lz)
hit in [max(t_min, t_enter), t_exit]  →  命中点自然落在中心域坐标
```

因为各副本区间按射线顺序排列，第一个命中即为整条周期射线的最近交，后续副本不能覆盖更近的中心域命中；命中距离、命中位置和命中查询起点（体元模式据此计算浊介质路径长度）都与一条连续直线射线一致。穿越次数由 `periodicTraversalCount`（0–20，0 表示开放边界）限制，计数单位是“一次自由程内跨越的边界数”：RayTracing 中每条相机、散射、阴影和天空射线各自计数，体元模式中两次相邻体元命中之间的一段射线计数；穿越不占用散射次数。显存不随副本数增长，计算量随有效穿越次数增加。为不把穿越次数浪费在场景上方的空域里，起点高于场景顶的下行射线（相机）从场景顶平面开始遍历，高于场景顶且不下行的射线直接判为逃逸。场景顶在 RayTracing 中取全部实例几何的最高点（主机端计算），在体元模式中取体元网格（NanoVDB 根节点包围盒）的最高层：任何相互作用都需要网格体元，因此这一截断是精确的（vrt_urban 算例开启与关闭截断，各输出均值完全相同）。

体元模式的浊介质出射积分（最后一次平面命中之后的 DDA 体元步进，VoxelRT 的 `TurbidEscapeTransmittance`、VoxelEB 散射的出射段源项）在周期边界下同样按周期环绕：DDA 在不取模的体元索引上推进，查表时把水平索引对 `N` 取模，跨越的副本数超过 `periodicTraversalCount`、离开网格竖直范围或透过率可忽略时停止。两次命中之间的浊介质段（`TurbidSegmentOpticalDepth`，从上一相互作用点到本次命中点）在副本中命中时，起点位于该副本坐标系的中心域之外：积分命中所在副本内的部分，以及自由程出发副本内的部分（即起点体元的出射段，平移整数个周期后在中心网格内积分）；中间穿过而无平面命中的副本不再积分，只可能漏掉斜穿体元角部的短路径，计算量因此固定为两次网格内 DDA，与穿越次数无关。

当前各模式的作用范围（2026-11-22 起）：RayTracing 的相机射线、散射射线、太阳阴影射线和天空 NEE 射线全部走周期遍历，阴影射线在每个副本内仍首次命中即终止；VoxelRT 的成像、太阳可见度、漫射/多次碰撞传输以及 VoxelEB 的成像、太阳、短波散射与长波（TIR）漫射传输全部走同一套周期遍历；FacetRT/FacetEB 按实例复制邻块（见 4.2 节）。成像射线在用完穿越次数后若仍下行，补查其落点所在副本的地面，避免远处出现空洞（仅成像）。限制：越出计算域边界的几何（例如树冠伸出域外的部分）在周期遍历中只在域内部分参与，伸出部分不会出现在对侧副本中；需要严格周期的场景应保证对象不跨越域边界（体元模式的网格本身也截在域内）。验证：把森林示例的树放在 25 m 规则格网上（树冠不出域，场景严格以 25 m 为周期），取 `periodicTraversalCount = 8`、太阳天顶角 30°，16 个格子中边缘 12 格与中心 4 格的均值差：VoxelRT 反射率与体元光照 ≤ 0.05%（只周期化成像时达 2.1%），VoxelEB 冠层净辐射 +0.01%、冠层温度差 0.00 K（此前边缘格净辐射低 14.8%、温度低 2.4 K），RayTracing ≤ 0.14%（此前 0.96%，残差为蒙特卡洛噪声）。

**RayTracing 路径终止。** 散射次数上限为独立参数 `raytracingDepth`（默认 16，上限 64）；从第 3 次散射起做俄罗斯轮盘赌，存活概率 q = clamp(max(β), 0.05, 1)（β 为路径通量），存活路径通量除以 q，因此估计无偏。阴影射线首次命中即终止，起点偏移 1 mm。

天空边界有两种表达：默认 cosine 半球分布，以及可选典型天空盒。前者以天顶角余弦权重描述各向异性漫射天空，后者把天空与云信息作为边界辐射纹理采样。天空盒改变进入域内的方向辐射，不创建额外实体，也不改变局部雾的体消光。

## 6. 异质性体元（1.1 重点）

异质性体元工作的核心不是增加更多几何副本，而是把一次性的精细几何统计转化为运行期可直接使用的体元参数。完整处理链为：

```text
OBJ 三角面
  → 计算域裁切与有效体元判定
  → 体元内三轴投影面积和联合遮挡掩膜
  → rho、CIx/CIy/CIz 与类别贡献
  → 紧凑结构描述符和最多两个主要类别
  → VoxelRT 消光/散射/热发射
  → VoxelEB 净辐射/能量通量/温度/GPP/NPP
  → 多波段、多角度、逐时间节点输出
```

因此，预处理阶段仍利用面元提供结构真值，正式计算阶段则保持体元求解。该设计避免均质体元把方向空隙率压缩成单一常数，也避免面元模型在大规模重复实例场景中展开全部三角形。

### 6.1 统计目标

异质性体元用于在较粗网格中保留真实亚体元结构，而不是在正式辐射传输阶段继续追踪体元内每一个对象。当前提取阶段统计：

```text
voxel = {rho, CIx, CIy, CIz, mixed spectral, mixed thermal}
```

首次占位只用于确定体元存在性和候选类型，不替代后续密度及遮挡统计。同一个体元中存在建筑、植被或其他多个类别时，各类别共同参与三轴投影遮挡统计。

### 6.2 三轴结构参数

分别沿 X、Y、Z 方向计算投影覆盖率 `C_x`、`C_y`、`C_z`。对方向 `q`：

```text
CI_q = -ln(1 - C_q) / A_projected,q
```

计算任意射线方向时，用方向向量绝对分量组合三个主轴参数：

```text
CI(omega) = weighted(CIx, CIy, CIz; |omega_x|, |omega_y|, |omega_z|)
```

`rho` 由体元内真实结构量统计得到，`CIx/CIy/CIz` 描述相同密度在不同方向上的遮挡效率。二者不能互相替代：密度回答“有多少结构”，CI 回答“结构如何排列并遮挡”。

### 6.3 多类别综合属性

当前实现按各类别在 X、Y、Z 三个方向上的遮挡贡献排序，只保留最重要的两个类别。设保留类别的三轴贡献为 `c_mx`、`c_my`、`c_mz`，综合权重概念上为：

```text
w_m = (c_mx + c_my + c_mz)
      / sum_n(c_nx + c_ny + c_nz)
```

工程中权重量化到 1/1024，以便稳定存储。两个类别的光谱和热属性按贡献加权：

```text
rho_mix(lambda) = sum_m[w_m rho_m(lambda)]
tau_mix(lambda) = sum_m[w_m tau_m(lambda)]
T_mix,state      = sum_m[w_m T_m,state]
```

若类别 A、B 的投影覆盖分别为 0.4 和 0.3，即使总覆盖因重叠而小于 0.7，类别权重仍按各自对三轴遮挡的贡献归一化，而不把重叠误当作新的第三类。完成综合后，RT/EB 阶段只读取这个体元的 `rho`、三轴 CI 和综合光谱/温度，不再追究内部具体对象。

当前限制是最多保留两个主要类别，较弱类别会被舍弃；因此异质性极强且类别贡献接近的粗体元应缩小体元大小并做分辨率敏感性试验。

### 6.4 与 VoxelRT/VoxelEB 的耦合

异质结构描述符中的 `rho` 和三轴 CI 直接进入 VoxelRT/VoxelEB 的方向消光。对单位方向 $\boldsymbol\omega=(\omega_x,\omega_y,\omega_z)$，当前实现先按绝对方向分量归一化组合：

$$
CI(\boldsymbol\omega)=
\frac{|\omega_x|CI_x+|\omega_y|CI_y+|\omega_z|CI_z}
{|\omega_x|+|\omega_y|+|\omega_z|},
$$

再以 $\rho GCI(\boldsymbol\omega)$ 构成体元内光学厚度。太阳方向和传感器方向分别取值，因此同一体元可以同时表现为某一方向空隙较多、另一方向遮挡较强。该项参与太阳可见性、天空入射、体元间交换和成像路径，不只是 Three.js 的显示颜色。

多类别体元的光谱和热状态按遮挡贡献综合后进入相同求解链。VoxelEB 由吸收短波、下行与邻近长波得到净辐射，再计算显热、潜热和储热/导热；植被类别进一步输出 GPP/NPP。异质性体元因而会通过辐射吸收和阳照比例间接改变能量平衡，而不是额外增加一套独立温度模型。

### 6.5 计算代价与验证

开启异质性体元会增加 OBJ 读取、体元内三轴投影和重叠掩膜合并的预处理时间；结构提取完成后，原始内部面元不在每次射线查询中重复展开。单体元核心结构描述符 `CIx/CIy/CIz/rho` 为 4 个浮点数，运行期主要增加方向 CI 组合和类别属性读取，计算量通常远小于完整面元展开，但仍高于关闭异质性的均质体元模式。

建议使用三组对照验证：一是同一体元大小下比较异质性开/关，检查冠层透过率、阴影比例、反射率和亮温方向性；二是逐步减小体元，检查异质体元结果是否趋于稳定；三是在可承受的小场景中与 FacetRT/FacetEB 比较。日志中的有效体元数、平均密度和提取耗时用于识别异常体元化；若密度极端、方向差异不合理或三个以上类别贡献接近，应检查 OBJ 重叠、法向、尺度、填充阈值和体元大小。

## 7. 能量平衡与温度演化

### 7.1 基本守恒关系

FacetEB 与 VoxelEB 在每个气象时间节点求解地表能量守恒。TRGM-EB 对阳面和阴面的原式分别为：

$$
R_{n,s}-H_s-\lambda E_s-G_s=0,
\tag{R1-9}
$$

$$
R_{n,h}-H_h-\lambda E_h-G_h=0.
\tag{R1-10}
$$

其中 $R_n$ 为净辐射，$H$ 为显热通量，$\lambda E$ 为潜热通量，$G$ 为土壤热通量，下标 $s$、$h$ 分别表示阳面和阴面。VoxelEB 水体以混合层储热 $Q_w$ 替代土壤热通量；FacetEB 水体目前按普通固体面处理，不蒸发、无混合层。

论文给出的面元阳面、阴面净辐射原式为：

$$
R_{n,s}(i)=\sum_\lambda
\left[\frac{F_s(i,\lambda)}{a(i,\theta_d)}+F_d(i,\lambda)
+\sum_jF_{i,j}B_j(\lambda)-F_e(i,\lambda)\right]
[1-\rho(i,\lambda)-\tau(i,\lambda)],
\tag{R1-6}
$$

$$
R_{n,h}(i)=\sum_\lambda
\left[F_d(i,\lambda)+\sum_jF_{i,j}B_j(\lambda)-F_e(i,\lambda)\right]
[1-\rho(i,\lambda)-\tau(i,\lambda)].
\tag{R1-7}
$$

宽波段热发射原式为：

$$
F_e(i)=\varepsilon_i\sigma T_i^4,
\qquad \sigma=5.6704\times10^{-8}\ \mathrm{W\,m^{-2}\,K^{-4}}.
\tag{R1-8}
$$

长波上行辐射随温度约按 `epsilon sigma T^4` 变化，使 RT 与 EB 形成非线性耦合。

### 7.2 显热与潜热

TRGM-EB 的显热和潜热原式为：

$$
H=\rho_a c_p\frac{T_s-T_a}{r_a},
\tag{R1-11}
$$

$$
\lambda E=\gamma\frac{q_s(T_s)-q_a}{r_a+r_s}.
\tag{R1-12}
$$

其中 $\rho_a$ 为空气密度，$c_p$ 为空气比热，$T_s$、$T_a$ 分别为表面与空气温度，$q_s$、$q_a$ 分别为表面饱和比湿与空气比湿，$r_a$、$r_s$ 分别为空气动力阻力和表面/气孔阻力，$\gamma$ 为水的汽化潜热。风速越大或空气动力阻力越小，表面与空气的显热交换越强。

论文的土壤表面阻力原式为：

$$
r_s=1.439\times10^5(\theta_{sat}-\theta_{0-5})^{3.14}.
\tag{R1-14}
$$

空气动力阻力由各高度区间串联：

$$
r_a^i=r_a^I+r_a^R+r_a^c+r_w^i+r_b^i.
\tag{R1-15}
$$

其中粗糙子层阻力 $r_a^R$（代码中的 rar）按下式计算，稳定度修正 $\psi^*$ 为无量纲量，须在 $1/(\kappa u_*)$ 括号内：

$$
r_a^R=\frac{1}{\kappa u_*}\left[\frac{z_r-h}{z_r-d}-\psi^*(z_r)+\psi^*(h)\right].
\tag{当前实现式}
$$

$z_r$ 为粗糙子层顶高度（参考高度低于 $z_r$ 时以参考高度 $z$ 代替），$h$ 为冠层高度，$d$ 为零平面位移。SCOPE `resistances.m`（及 TIRTEB）把右括号提前闭合，等于把无量纲项直接加减在 s m⁻¹ 量纲的阻力上，中性层结 $\psi^*=0$ 时两者相同。2026-11-20 起 VoxelEB 与 STREAM 均用上式；STREAM 非中性像元的组分温度随之变化。VoxelEB 开启稳定度修正后（见下文“VoxelEB Monin–Obukhov 稳定度迭代”），$\psi^*$ 项采用与 FacetEB 相同的积分形式：$r_a^R=\frac{1}{\kappa u_*}\frac{z_r-h}{z_r-d}\,\overline{\phi_H}$，$\overline{\phi_H}$ 为 $[h,\min(z,z_r)]$ 上 8 点中点平均。

VoxelEB 的对数风廓线以参考高度风速为输入；流场开启时，解析的局地风速只用于 localExchange 交换模式和建筑类固体（含树干、枝条）的强迫对流系数，不再代入对数廓线重复折减。

**VoxelEB 地面自由对流（2026-11-22）。** 中性层结下（`control.stabilityCorrection` 关闭），低风速时地面交换几乎消失，光照土壤 G/Rn 曾达 0.9。现对土壤、水体和建筑表面，在表面温度高于气温（不稳定）时并联加入 Kondo & Ishida（1997）、TSEB（Kustas & Norman 1999）的无风导度：

$$
g_{free}=0.0025\,x\,(x^2+1)^{-1/3}\ \mathrm{m\,s^{-1}},\qquad x=\min(T_s-T_a,\,60\ \mathrm K),
\qquad \frac{1}{r_{a,eff}}=\frac{1}{r_a}+g_{free}.
\tag{当前实现式}
$$

该式在 x ≫ 1 时趋于 0.0025·ΔT^{1/3}，在 x = 0 处斜率有限，能量平衡的 Newton 更新不会在 Ts = Ta 附近振荡；evapo 与 budget 两处使用同一有效阻抗，显热线性化中计入 g_free 的导数。稳定或中性层结与植被不变。示例中正午土壤 H 由 7–14 W m⁻² 升到 30–66 W m⁻²，G/Rn 降到 0.76–0.84；剩余偏高主要来自示例土壤热惯量（√(λC) ≈ 2200，近湿黏土）。

**VoxelEB Monin–Obukhov 稳定度迭代（2026-11-22）。** `control.stabilityCorrection = true` 时，VoxelEB 在能量平衡迭代中求场景 Obukhov 长度 $L$，相似函数与 FacetEB（`energyphysics.h`）一致：不稳定用 Paulson 形式，稳定用线性形式 $\psi_M=\psi_H=-5\zeta$、$\phi_H=1+5\zeta$，$\zeta=(z-d)/L$ 限于 $[-5,1]$。

1. 每次 budget 扫描时，按本次交换通量累加场景显热（每地面面积）：叶片体元取 $2\bar H\cdot\mathrm{LAD}\cdot\Delta^3/\Delta^2$（两面，$\bar H$ 为阳/阴面按光照比例混合），土壤、水体、建筑状态各取一个 $\Delta^2$ 面元，总和除以域水平面积 $N_xN_z\Delta^2$；
2. 气动阻抗扫描（aeresist）对每个土壤/水体体元，用其所在柱的冠层（或裸土）参数计算 $u_*$ 与 $z-d$，取地面柱平均；
3. 目标 $1/L^\ast=-\kappa g H/(\rho c_p T_a u_*^3)$，按 $\zeta$ 限幅后以 0.5 松弛：$1/L\leftarrow 1/L+0.5(1/L^\ast-1/L)$；每次 $1/L$ 变化都重算全部气动阻抗（aeresist 只遍历体元一次，成本远小于长波扫描）；
4. 提前退出同时要求全部状态能量残差 < 2 W m⁻² 与 $|\Delta\zeta|\le 0.02+0.02|\zeta|$。每节点从中性开始，结果与节点划分无关。

阻抗中 $u_*$、惯性子层 $r_a^I$、粗糙子层 $r_a^R$、冠层内扩散系数 $K_h=\kappa u_*(z_r-d)/\phi_H((h-d)/L)$（进入 $r_a^c$ 与林下 $r_w$）及 $u_h$ 均使用 $1/L$。归约用定点整数原子累加（显热 0.1 W m⁻²、$u_*$ 1e-4 m s⁻¹），结果与线程顺序无关、重复运行逐位一致。场景无土壤/水体柱时该节点退回中性；localExchange 模式不使用该修正。

开启修正时，地面自由对流不再并联而改为取大：$1/r_{a,eff}=\max(1/r_a,\ g_{free})$。MOST 的不稳定修正已包含浮力对交换的增强，再并联 $g_{free}$ 会重复计入；取大让 MOST 负责强迫/混合对流，无风极限仍由 $g_{free}$ 托底。关闭时着色器使用与旧版逐字一致的中性管线（`*_most.comp.spv` 为 `-DVOXELEB_MOST` 单独编译），结果与旧版逐位相同。

回归示例（forest、urban_block，正午 u = 0.43–0.50 m s⁻¹）：正午 ζ 收敛到 −4.9（接近不稳定限幅），$u_*$ 0.04–0.07 m s⁻¹；叶片温度下降 2.7–6.2 K（森林 305.4→300.2 K，气温 299.7 K），LE 增加 33–69%；土壤 H、G/Rn 基本不变（取大后与原并联自由对流相当，G/Rn 仍 0.77–0.84，偏高源于土壤热惯量）。夜间（01:50、02:20，初始地温低于气温）ζ 收敛到稳定限幅 +1，$u_*$ 降至 0.007–0.04 m s⁻¹，土壤与叶片显热绝对值降低约 3 倍，叶温再降 0.3–1.6 K。迭代次数 7–27（≤50），无振荡，耗时增加 ≤ 6%。场景单一 $L$ 是对异质场景的近似；低风速正午常落在 ζ = −5 限幅附近，此时结果对限幅取值敏感。

当前植被可选择 Ball–Berry 或 Farquhar 机制求取光合—气孔响应；FacetEB 的机制法为 SCOPE MD12（C3 Farquhar、C4 von Caemmerer，Ball–Berry 气孔耦合），不是 Jarvis 式。土壤蒸发同时受含水量和表面阻力限制。

这意味着光照土壤不一定必然比植被热。若土壤导热/储热强、反照率高或蒸发旺盛，而植被蒸腾受限，土壤模拟温度可能更低。比较 FacetEB 与 VoxelEB 时，应首先对齐净辐射、空气动力阻力、土壤热通量、含水量和阳/阴面比例，而不是只比较最终温度。

### 7.3 土壤、水体与植被温度

土壤支持三类时间处理：瞬时能量平衡、热惯性动态和温度廓线传导。温度廓线传导模式中，每个土壤体元对应一条实际的一维土柱；阳照和阴影状态只用于求解表面能量平衡，随后按当前阳照比例合成实际表面温度作为土柱上边界。0、0.02、0.04、0.10、0.20、0.40、0.60 和 1.00 m 为离散节点，最深的 1.00 m 节点使用材料参数 `Tsoil` 作为固定温度边界，因此短时阳影差异应随深度迅速衰减，不能完整延伸至 1 m。以上为 VoxelEB 的土柱；FacetEB 方法 2 的土柱为 12 层有限体积、深 3 m（层界 0、0.01、0.025、0.05、0.1、0.2、0.35、0.55、0.8、1.1、1.5、2、3 m），每个地面面元的晴、阴状态各一条剖面，后向欧拉推进，底边界固定为初始温度（`Tsold`；工程未写时取首个气象节点气温，GUI 总会写出数值，默认 300 K）。

**晴/阴两态热历史的面积守恒转移。** FacetEB 每个面元侧（以及 VoxelEB 土壤方法 1 的每个固体体元）把表面分成受光部分（面积比例 $p$）和阴影部分（$1-p$），两部分各自保存热历史：结构面元的表面温度（储热 $C\,\partial T/\partial t$ 的上一时刻值）、方法 1 的前 8 个节点表面温度序列、FacetEB 方法 2 的 12 层土柱剖面。太阳移动使 $p$ 在相邻节点间从 $p_\text{old}$ 变为 $p_\text{new}$ 时，改变状态的那部分面积必须带着自己的热历史转移；否则新进入阴影的面积会沿用"一直处在阴影中"的冷历史，其储热凭空消失（反之亦然）。每个节点开始时按面积守恒重映射：

$$
p_\text{new}<p_\text{old}:\quad
X_\text{阴}'=\frac{(1-p_\text{old})X_\text{阴}+(p_\text{old}-p_\text{new})X_\text{晴}}{1-p_\text{new}},\quad X_\text{晴}'=X_\text{晴};
$$

$$
p_\text{new}>p_\text{old}:\quad
X_\text{晴}'=\frac{p_\text{old}X_\text{晴}+(p_\text{new}-p_\text{old})X_\text{阴}}{p_\text{new}},\quad X_\text{阴}'=X_\text{阴}.
$$

$X$ 依次取上述每个历史量（同一面元的热容相同，温度的面积加权即热含量的面积加权），于是 $p_\text{new}X_\text{晴}'+(1-p_\text{new})X_\text{阴}'=p_\text{old}X_\text{晴}+(1-p_\text{old})X_\text{阴}$，总热含量 $\sum pCT$ 不变；方法 1 的传导通量对历史是线性的，重映射同样保持其隐含储热。$p$ 不变的面元不做任何改动。集中参数热节点（`lumpedThermal`）的内部节点只有一个温度，不分晴阴，无需转移，其表皮两态随上式转移。VoxelEB 方法 1 在体元温度记录中保存上次写历史时的阳照比例，`evapo.comp` 每次迭代按当前比例计算转移后的历史，`updateTp.comp` 在节点末提交同一转移后再推进历史；VoxelEB 方法 2 本来就是一条混合土柱，水体为单一混合层，均不受影响。选择守恒转移而非"单一混合历史"，是因为后者把晴阴两态的历史都替换为平均值：对长期部分遮挡、晴阴不交换的表面，方法 1 的受光态会因此多算约 $\Gamma'\,(T_\text{晴}-\bar T)$ 的储热通量（$\Gamma'=2\Gamma/\sqrt{\pi\Delta t}$，典型土壤约 40 W m⁻² K⁻¹），破坏两态温差；守恒转移在 $p$ 只取 0/1 时与单一历史相同，在部分遮挡时仍保留两态差异。

在城市街区示例 08:50–13:20 共 10 个 30 min 节点的专项算例（`feb_urban_shadow`、`feb_urban_shadow_m1`、`veb_urban_shadow_m1`）中，旧做法的误差为：阴影到达（$p$ 一个节点内下降超过 0.5）的地面面元，到达节点的地表温度平均偏低 7.1 K（方法 2）/ 7.8 K（方法 1），最大偏低 18–20 K，其后 1、2 个节点仍偏低约 4.7–5.2 K、2.6–2.8 K；地表储热通量 G 平均多算 70–77 W m⁻²；建筑面元偏低约 1.4 K（最大 4–6 K），叶片约 0.25 K。按节点统计的热含量闭合残差 $[\sum pCT]_{n}-[\sum pCT]_{n-1}-\Delta t\,\bar G$ 在旧做法中，土壤（方法 2）面积平均 |残差| 为 5–42 W m⁻²（随两态剖面分化逐节点增大，单面元最大约 3000 W m⁻²），结构面元为 1–7 W m⁻²；守恒转移后两者均为 0（浮点舍入内）。VoxelEB 方法 1 土壤体元在阴影到达节点平均偏低 6.6 K（最大 14 K），建筑体元 1.7 K（最大 9.7 K），G 多算约 97 / 32 W m⁻²。另以诊断开关 `HISTREAM_THERMAL_HISTORY=mixed`（每节点把两态合并为单一面积加权历史）作独立参考：在阴影到达面元上它与守恒转移的差别平均 0.003 K、全场最大 0.4 K，说明该场景中面元的 $p$ 基本是 0/1，转移后的结果就是单一历史的正确解。`HISTREAM_THERMAL_HISTORY=legacy` 复现旧做法，仅供对照。FacetEB 每个节点的 `diagnostics/facet_physics_node=*.json` 中 `thermalHistory` 记录转移的面元侧数、旧做法会产生的热量跳变（J）与上述闭合残差（W m⁻²）。

TRGM-EB 的 force-restore 温度更新原式为：

$$
T_s(t+\Delta t)-T_s(t)
=\frac{\sqrt{2\omega}}{\Gamma}\Delta t\,G(t)
-\omega\Delta t[T_s(t)-\overline{T_s}].
\tag{R1-13}
$$

其中 $\omega$ 为日周期角频率，$\Gamma$ 为土壤热惯量，$\overline{T_s}$ 为年平均温度。热惯性或传导方案会把当前能量输入的一部分存入下层，使表面温度响应具有滞后。

水体在 VoxelEB 中使用混合层温度表达（FacetEB 水体无蒸发、无混合层，见 7.1 节）：

$$
\rho_wc_{p,w}h_{mix}\frac{dT_w}{dt}=R_n-H-\lambda E.
\tag{当前实现式}
$$

混合层越深，等效热容量越大，日间升温和夜间降温越慢。当前模型是简化的一维储热表达，不计算三维水动力、分层和水平输运。

植被温度通过叶片净辐射、显热和蒸腾耦合更新。光合—气孔方案的作用是把辐射、二氧化碳交换和水分损失连接起来，而不是简单指定一个固定叶温。

### 7.4 植被碳同化与 GPP/NPP

VoxelEB 在植被生化—气孔耦合中得到叶片总光合速率 `Ag` 与暗呼吸 `Rd`。当前过程输出定义为：

```text
GPP = max(0, Ag)
NPP_leaf ~= Ag - Rd
```

单位均为 `μmol CO₂ m⁻²叶面积 s⁻¹`。阳面与阴面分别计算后，按照体元内当前受光比例加权合并；非植被体元写 0。C4 Farquhar 分支同样按 `Ag = A + Rd` 恢复总光合，再由上式输出，因此白天 GPP 一般为正，夜间接近 0，而 NPP 可因暗呼吸为负。

这里的 `NPP_leaf` 是当前叶片尺度净同化近似，并未扣除根、茎、维持和生长等全部自养呼吸，也未从瞬时叶面积尺度积分到日、月或单位地表面积。若需生态系统碳收支，应先按叶面积密度和时间积分转换尺度，再显式加入非叶器官呼吸；不能把当前瞬时 `npp` 直接解释为严格生态学 NPP。

### 7.5 RT–EB 迭代

每个时间节点的概念流程为：

```text
气象与太阳位置
  -> 短波直射/漫射传输
  -> 长波场景交换
  -> 净辐射与湍流/传导通量
  -> 更新温度
  -> 按松弛系数回写
  -> 温差收敛后输出
```

当前工程的温度松弛写为：

$$
T^{n+1}=(1-\eta)T^n+\eta T_{solved}^{n+1}.
\tag{当前实现式}
$$

$\eta$ 过大可能振荡，过小则收敛慢。达到收敛判据或最大耦合迭代数后结束。FacetEB 新工程默认 η = 0.8（原 0.5）。FacetEB 的节点收敛判据为：|残差| ≥ 2 W m⁻² 的面元少于全部面元的 0.1%，且所有面元侧的温度等效残差 |R|/(∂R/∂T) ≤ 0.5 K（另要求集中参数热节点残差 < 2 W m⁻²）；`temperatureTolerance` 只写入运行记录，不参与判断。只看 0.1% 比例时，节点可能在少数面元残差达数十 W m⁻²（> 1 K）时被判为收敛，因此加入温度等效上限。未收敛节点保留结果并继续，引擎以退出码 2 结束。

VoxelEB 的温度更新不读工程中的松弛系数，阻尼随迭代递减：非植被 η = 0.9（第 1–8 次）→ 0.5（第 9–20 次）→ 0.25，植被 0.5 → 0.3 → 0.2；上限 50 次，判据为全部体元能量残差 < 2 W m⁻²。

### 7.6 逐节点输出与内存生命周期

能量平衡任务按气象节点推进。FacetEB 的结果后处理以单个时间节点为内存边界：读取当前节点临时数据，完成该节点各观测角的 TIFF、辐射过程和能量过程索引后立即释放数组；最后一个观测角处理完成后删除对应临时 `.bin`。实现不再用常驻映射保存全部节点，也不会把第一个节点数据保留到末尾。

因此峰值后处理内存主要受单节点的影像分辨率、波段数、观测角以及面元过程字段影响，而不再随全部时间节点近似线性累加。体元与引擎内部显存仍由场景体元数、采样数和过程输出共同决定，逐节点释放不能消除过细体元或超高分辨率本身的资源需求。

## 8. 光谱窗口加速

### 8.1 能量积分与传感器波段的区别

能量平衡需要的是整个短波范围的总吸收能量，而最终遥感图像需要指定传感器波段。因此计算被分为两条用途不同的光谱路径：

```text
短波窗口积分 -> Rn -> 温度
传感器波段逐波长/逐响应计算 -> 最终图像
```

短波净辐射对波长积分：

```text
SW_abs = integral[E_sun(lambda) * A(lambda) d lambda]
```

当前默认窗口宽度为 100 nm。每个窗口分别处理直射和漫射，再累加为总短波净辐射。窗口越窄越能保留太阳光谱和材料吸收的窄带变化，但求解次数更多；窗口越宽速度更快，但不适合跨越明显吸收带。

### 8.2 FacetEB 与 VoxelEB

FacetEB 的 100 nm 设置作用于短波净辐射窗口积分，窗口结果驱动温度；完成能量平衡后，用户选择的 1–6 个或更多传感器波段仍独立成像。VoxelEB 的直射与漫射短波计算均服从相同窗口宽度。两种模式由同一个界面参数控制，以保持研究设置一致。

光谱窗口不等于图像波段宽度，也不意味着把窗口中心结果复制给窗口内所有最终输出波段。

## 9. 热红外方向性与背景异质性

### 9.1 方向性来源

同一场景在不同观测方向出现不同亮度温度，主要来自：

- 不同方向可见的阳面、阴面、土壤和植被比例不同；
- 组分物理温度与发射率不同；
- 热红外在结构内部发生遮挡和多次散射；
- 地形坡向改变局部入射角、可见性和温度；
- 大气路径随观测天顶角增长。

方向性研究应优先比较辐亮度或亮度温度相对天底方向的差值，并保证各方向使用同一时刻的组分温度。跨较长时间获取的多角度实测数据，需要先消除温度时间漂移。

Bian et al.（2025）的组分热红外方向辐亮度式直接表明，方向变化通过 $f_j(\theta_s,\theta_v,\phi)$ 和 $\varepsilon_{m,j}$ 进入：

$$
L(\theta_s,\theta_v,\phi)
=\sum_j[\varepsilon_jf_j(\theta_s,\theta_v,\phi)+\varepsilon_{m,j}]
B_\lambda(T_j)+r_cL_a^\downarrow .
\tag{R10-1}
$$

### 9.2 背景 Hapke 角度效应

当前背景可在各向同性结果和 Hapke 型方向响应之间插值：

```text
R_used = (1 - s) R_Lambert + s R_Hapke
E_used = (1 - s) E_isotropic + s E_Hapke
```

`s` 为界面保留的结构强度参数，范围 0–1。光学波段用于调整背景方向反射权重，热红外用于调整方向发射率。内部形状参数固定，使光谱颜色主要仍由材质属性决定。

FacetRT/FacetEB 中，上式的 Hapke 因子在天底归一化且不含热点，其半球积分高于 Lambert 值（底值 0.2 时约 1.3–2.5 倍），不能直接用于能量收支。因此两类用途分开：

```text
影像：R_used、E_used 取天顶观测方向的方向反射因子/方向发射率
能量：R_dif = R_Lambert
      R_dir = R_Lambert · A(mu0) / A_bh
      R_Hapke,energy = (E_dir R_dir + E_dif R_dif) / (E_dir + E_dif)
      长波取 Lambert 半球发射率
```

即 Lambert 底值作为白空（双半球）反照率，天空漫射按底值反射，直射只保留 Hapke 随太阳角的相对变化；A(μ0) 为截断后 Hapke 因子的方向—半球反照率，A_bh 为其双半球积分，按直射/漫射通量加权后再与 Lambert 值按 `s` 插值。`s = 0` 时结果不变。

该简化参数适合表达背景粗糙度造成的角度效应，但不能替代真实微地形、完整 Hapke 参数反演或地表温度阴阳分布。

### 9.3 三类方向性模型的关系

物理三维模型直接表达结构和组分温度，可解释性强但计算量大；解析参数模型将场景压缩为少量结构和温差参数；核驱动模型用经验核拟合方向变化，约束少且反演快。三者没有对所有场景都最优的方法：规则行结构通常更需要显式几何，而均质或稀疏场景可用参数模型快速近似。

论文中物理混合模型的植被可见比例原式为：

$$
f_c(\mathbf r_v)=\lambda\int_Vp_0(x,y,z,\mathbf r_v)
\,u_L\frac{G}{\mu_v}\,dx\,dy\,dz,
\tag{R10-2}
$$

$$
p_0(x,y,z,\mathbf r_v)=p_i(x,y,z,\mathbf r_v)p_b(z,\mathbf r_v).
\tag{R10-3}
$$

其中 $p_i$、$p_b$ 分别是冠层个体内部与个体之间的方向空隙概率。解析参数模型用方向团聚指数修正 Beer–Lambert 定律：

$$
f_s(\mathbf r_v)=b(LAI)=\exp\left(-\frac{G\Omega LAI}{\mu}\right).
\tag{R10-9}
$$

论文采用的核驱动模型原式为：

$$
T(\theta_s,\theta_v,\Delta\phi)
=f_{com}K_{com}(\theta_s,\theta_v,\Delta\phi)
+f_{geo}K_{geo}(\theta_s,\theta_v,\Delta\phi)+f_{iso},
\tag{R10-18}
$$

$$
K_{com}=1-\cos\theta_v,
\tag{R10-19}
$$

$$
K_{geo}=\sec\theta_s'+\sec\theta_v'-O,
\tag{R10-20}
$$

$$
O=\frac{1}{\pi}(t-\sin t\cos t)
(\sec\theta_s'+\sec\theta_v').
\tag{R10-21}
$$

当前 Stream Studio 的 FacetRT/VoxelRT 属于物理三维正向框架。解析参数化与核驱动拟合可作为结果后处理或未来快速代理，但尚未替代当前求解器。

## 10. 水体辐射与温度

### 10.1 水面方向反射

当前水体表面使用 Fresnel–Cox–Munk 参数化。Fresnel 项由入射角和水体折射率决定，Cox–Munk 项用微表面坡度分布表示波浪法向概率：

```text
BRDF_water = Fresnel(theta_h, n)
             * SlopeDistribution(sigma_slope)
             * geometric factor
             + diffuse fraction
```

太阳方向、观测方向和微表面法向接近镜面条件时出现太阳耀斑。坡度方差越大，高光区域通常更宽、更弱；方差越小，镜面峰更集中。Three.js 的动态波浪只服务预览，真实辐射图像由水体 BRDF 参数决定，两者当前不共享逐顶点波形。

### 10.2 水温

水温由净辐射、显热、蒸发和混合层储热共同更新（VoxelEB；FacetEB 水体不蒸发、无混合层）。该近似适用于水面遥感信号、耀斑影响和日变化研究，不适用于波浪破碎、三维流场、深水分层或水下辐射传输研究。

## 11. 火焰与雾参与介质

### 11.1 简化表达

火焰与局部雾用于 VoxelRT/VoxelEB。用户给定一个三维区域，程序将其体元化为具有消光、吸收、发射和散射特性的参与介质。火焰使用收窄的上升形态，雾填充完整的椭球或立方体包络。局部雾已进入 VoxelRT 和 VoxelEB 的辐射路径；它与 MODTRAN 表达的大尺度均匀雾霾是两层不同的介质。沿路径 `s` 的形式解为：

```text
L_out = L_in exp(-kappa s)
        + B_lambda(T_fire) [1 - exp(-kappa s)]
```

若考虑散射，还应增加入射辐射的体散射源项。当前光学图像对烟/雾只计单次散射，每个介质体元贡献（与叶片项相同，以 πL 累加）：

$$
\pi L=\omega\left(1-e^{-\tau}\right)\left[\pi\,p(\Theta)\,E_b\,T_{sun}+\tfrac12 E_{env}\right],
\tag{当前实现式}
$$

其中 $\omega$ 为单次散射反照率，$\tau$ 为体元内光学厚度，$p(\Theta)$ 为按每球面度归一的 HG 相函数，$E_b$ 为法向直射辐照度，$T_{sun}$ 为到太阳的透过率，$E_{env}$ 为体元两面合计的环境辐照（VoxelEB 为天空漫射 × 无碰撞天空比例，VoxelRT 为漫射追踪得到的环境场），各向同性散射取其一半。热红外波段在 2.5–6 μm 计太阳项（绝对辐照、按 L 累加，见“中波红外太阳反射”），> 6 μm 不计。当前简化模式的核心用途是生成林下或地表火点在热红外传感器中的辐射表现，并评估其经过冠层遮挡、大气衰减和空间混合后能否被航空或卫星传感器识别。

### 11.2 与真实燃烧的边界

当前火焰形态是可视化与等效介质参数化，不求解燃料热解、化学反应、湍流燃烧和火线蔓延。需要特别区分：用户设置的局部雾已经按参与介质进入最终辐射计算；VoxelEB 流体输送产生的烟雾浓度场目前只用于过程分析，尚未反馈到最终辐射图像。因此该模块适合火点探测敏感性试验，不适合火行为预报。

## 12. 简化流体耦合

### 12.1 控制方程

流体模块当前只接入 VoxelEB，用于建立场景尺度的风速与气温场。其理论基础是带浮力和多孔阻力的不可压缩流动：

```text
div(u) = 0

du/dt + (u dot grad)u
  = -grad(p)/rho_air + nu laplacian(u)
    + buoyancy - canopy_drag

dTa/dt + u dot grad(Ta)
  = kappa_T laplacian(Ta) + surface_heat_source
```

当前流动数值实现采用 D3Q19 格子玻尔兹曼方法。分布函数通过 BGK 碰撞和拉取式迁移演化，宏观密度与速度由离散分布恢复；压力由状态关系 `p = cs² rho` 给出，不再求解全局压力 Poisson 方程。整次模拟使用固定的物理速度—格子速度比例，保证气象节点切换时已有分布函数保持同一物理含义；每个节点至少迭代一个来流穿越时间，以近稳态方式更新局地风场。温度与烟雾仍采用半拉格朗日平流和六邻域扩散，并在该节点的物理时间区间内推进。热浮力使用 Guo 力项，树冠作为带 LAD 的多孔阻力区，建筑采用半格反弹固体边界。耦合采用显式交错顺序：流体先读取上一节点更新后的表面温度，再将当前节点的局地风速和空气温度提供给空气动力阻力、显热和潜热计算。

### 12.2 边界条件

来流边界由气象风速和界面风向确定：上游为定值入口，下游为开放出口，侧边为自由滑移，顶部采用开放/弱约束处理。外边界不是四周刚性壁，因此均匀来流不应无条件向场景中心汇聚。

固体内不定义有效空气速度和气温，输出时写为 NoData。请求的 2 m 高度会解析到最近流体体元中心；若流体体元较粗，实际高度可能偏离 2 m。

### 12.3 适用范围

该模块用于把均匀气象来流调整为受建筑、植被和热浮力影响的近地风温场，并反馈显热交换。它不是经过工程验证的 LES/RANS CFD 求解器。对于 5 km 城市等大场景，应先使用 10 m 级流体网格；对于 500 m 植被场景可使用 1 m 级网格，并通过守恒、网格敏感性和实测剖面验证。

## 14. 模拟—观测融合与基础参数校准

### 14.1 可识别参数优先级

只有红边和热红外图像时，信息量不足以同时反演大量结构、光谱、温度和空气动力参数。推荐保留场景几何与类别不变，只校准少数可识别参数：

- 类别层：植被红边反射率尺度、土壤/建筑光谱尺度、热红外发射率、植被和非植被温度偏差；
- 体元层：仅校准结构密度或一个结构尺度系数，不逐体元同时修改全部光谱和温度；
- 全局层：一个大气水汽修正或辐射定标偏差。

观测值可作为带不确定度的相对真值，而不是绝对无误差真值。工程校准可使用带先验约束的目标函数：

```text
J(theta) = sum_b ||W_b [I_sim,b(theta) - I_obs,b]||^2
           + lambda ||theta - theta_prior||^2
```

该式是建议的工程目标函数，不是上述论文的原式。Bian et al.（2025）将方向观测写成：

$$
\mathbf y=\mathbf X\mathbf c+\boldsymbol\epsilon,
\tag{R10-28}
$$

并使用最小二乘估计：

$$
\hat{\mathbf c}=(\mathbf X^T\mathbf X)^{-1}\mathbf X^T\mathbf y.
\tag{R10-30}
$$

采用 $\mathbf X=\mathbf Q\mathbf R$ 的 QR 分解时：

$$
\hat{\mathbf c}=\mathbf R^{-1}(\mathbf R^T)^{-1}
\mathbf X^T\mathbf y.
\tag{R10-31}
$$

第一项拟合观测，第二项约束参数不要无依据地远离初猜。类别参数应先校准，再在残差具有稳定空间结构时增加体元修正。

### 14.2 求导与优化

当前引擎不是端到端自动微分求解器。最稳健的基础方案是有限差分敏感度：

```text
dI/dtheta_i ~= [I(theta_i + delta) - I(theta_i - delta)] / (2 delta)
```

再用少参数 Gauss–Newton、L-BFGS 或网格/贝叶斯优化。可微渲染是在同一计算图中通过自动微分或伴随法直接得到梯度，参数多时更高效，但体元离散、遮挡突变、随机采样和 Vulkan 自定义 Shader 都会使完整可微实现明显复杂。

Li et al.（2025）的异质场景像元辐亮度采样原式为：

$$
L_{ij}=\frac{1}{N_{sample}}\sum_{n=1}^{N_{sample}}
\left[\varepsilon_nB(T_{ij})+(1-\varepsilon_n)R_{multi,n}\right],
\tag{R9-3}
$$

$$
R_{multi,n}=\frac{1}{M_{dir}}\sum_{m=1}^{M_{dir}}
\begin{cases}
\varepsilon_{m,n}B(T_{m,n}), & next=Scene,\\
L_{atm}^{\downarrow}, & next=Sky.
\end{cases}
\tag{R9-4}
$$

像元辐亮度关系写成线性系统：

$$
\mathbf L_{target}=\mathbf W\mathbf R_{pixel}.
\tag{R9-5}
$$

其 Jacobi 温度更新原式为：

$$
B\left(T_{ij}^{(k+1)}\right)=
\frac{1}{N_{sample}}\sum_{n=1}^{N_{sample}}
\frac{L_{ij}-(1-\varepsilon_n)\dfrac{1}{M_{dir}}
\sum_{m=1}^{M_{dir}}\varepsilon_{m,n}B(T_{m,n}^{(k)})}
{\varepsilon_n}.
\tag{R9-6}
$$

这是基于三维热红外邻近效应反演像元温度的论文方法，并非当前 Stream Studio GUI 已提供的反演按钮。它可作为后续观测融合模块的直接理论基础。

深度学习更适合在大量高质量模拟—观测样本存在时充当代理模型、初值估计器或残差校正器，不应在少量观测下直接替代物理模型。建议保留传统求解器作为基准，并把学习方法作为独立加速/校正函数。

## 15. 地表温度与组分温度反演

前 14 章都是正向问题：给定结构、光谱、温度、几何和大气，求出传感器可观测的辐亮度、反射率或亮温。本章说明把同一条链反过来求解地表温度时的数学形式，以及它接入 Stream Studio 与 HiStream 同化链时的约定。

反演在工程上分两类目标：

| 目标 | 未知量 | 典型观测 | 可行性 |
|---|---|---|---|
| LST（地表温度） | 1 个像元等效方向辐射温度 | 单/双热红外波段、单角度 | 分裂窗为基线，成熟可业务化 |
| LSCT（组分温度） | Tss/Tsh/Tls/Tlh 四个组分温度 | 多角度/多波段热红外 + 光学先验 | 单角度单波段欠定，必须加先验或空间/时间约束 |

**实现归属。** 卫星级分裂窗 LST、多角度/窗口 LSCT 与产品链由 LS4T（`C:\work\ls4t`）承担。STREAM 引擎与工作台另外内建了以 STREAM 正向热红外模型为观测算子的 LST / LSCT 影像反演（15.6 节，`inversion` 配置块）；LAI、土壤水分等参数的联合同化仍属**扩展方向**。`tools/stream-inverse/` 是单像元可微原型，不是产品反演器。工程接口、产品字段与已知缺口见 [lst-lsct-inversion.md](lst-lsct-inversion.md)。

### 15.1 反演问题与可识别性

观测算子把控制变量 x 映射为观测 y：

```text
y = H(x) + eps
```

其中 H 是第 3–13 章的正向链在传感器波段、观测角度和像元尺度上的复合，`eps` 包含传感器噪声、代表性误差、大气与结构误差。反演求解

```text
x_hat = argmin_x || y - H(x) ||_R^2 + || x - x_b ||_B^2 + 平滑项
```

三项分别是观测失配、背景（先验）约束和空间/时间平滑。第一项单独使用在观测数小于等于未知量且 H 病态时不可解，后两项决定问题是否适定。

可识别性由观测信息量而非优化器决定，结论有三条：

1. **温度—发射率退化**：单波段热红外只有 1 个观测，无法同时确定温度与发射率。发射率必须外部给定，或使用两个以上热红外波段。
2. **LST 可识别，LSCT 不自动可识别**：方向亮温在给定发射率与大气后唯一确定一个等效温度；四个组分温度需要四个以上彼此独立的观测（多角度、多波段组合）才能分离。
3. **结构只作输入或慢变先验**：LAI、冠层高度、叶倾角分布在热红外上的信息很弱，本轮反演目标不包含它们；其误差进入模型误差协方差，并按产品 QA 标注。

### 15.2 分裂窗地表温度反演（当前实现）

LS4T 的 `SplitWindowModel` 是一套八特征广义分裂窗，AATSR、SLSTR、MSG、MODIS、VIIRS、AHI、ASTER 共用这一核心，传感器模块只做数据映射。

先由两波段亮温与发射率构造辅助量：

```text
eps_mean = (eps1 + eps2) / 2
d_eps    = eps1 - eps2
bt_mean  = (bt1 + bt2) / 2
d_bt     = (bt1 - bt2) / 2
```

八特征向量为：

```text
f1 = 1
f2 = bt_mean
f3 = (1 - eps_mean) / eps_mean * bt_mean
f4 = d_eps / eps_mean^2 * bt_mean
f5 = d_bt
f6 = (1 - eps_mean) / eps_mean * d_bt
f7 = d_eps / eps_mean^2 * d_bt
f8 = (bt1 - bt2)^2

T_s = sum_k c_k(VZA, wv) * f_k
```

系数 `c` 是形状为 `(VZA 节点, 水汽分箱边界, 8)` 的三维数组：VZA 在相邻节点之间线性插值，柱水汽只按分箱选择、不插值。**不做外推**：VZA 允许落在最末节点上，水汽落在最末边界外即判无效。分裂窗系数按传感器与大气条件标定，标定域之外的场景不应使用。

输入有效性与质量标记：

| 条件 | 处理 |
|---|---|
| 亮温或发射率为非有限值，亮温 ≤ 0，发射率不在 `(0, 1]` | 置 NoData，标记 `INPUT_INVALID` |
| 云掩膜为真 | 置 NoData，标记 `CLOUD` |
| VZA 或水汽超出标定域 | 置 NoData，标记 `INPUT_INVALID` |
| 结果超出 220–365 K | 置 NoData，标记 `OUT_OF_RANGE` |

分裂窗只给一个等效方向温度，不能分离组分温度。城市、作物行结构等异质像元得到的是像元等效辐射温度，与任一真实表面温度都不相等。

### 15.3 覆盖率与混合有效发射率（当前实现）

分裂窗需要两个波段的像元有效发射率。当前实现先由 LAI 求方向植被覆盖率，再按土壤—植被—多次散射混合：

```text
f = 1 - exp(-G * LAI / cos(VZA))，G = 0.5
eps = eps_s (1 - f) + eps_v f + F (1 - eps_s) eps_v (1 - f)
eps = min(eps, 0.995)
```

`F` 是多次散射的经验因子，公共核心默认 `F = 0.75`，部分历史案例使用 `F = 0.05`。两者数值差异直接进入 LST，**同一批产品必须记录所用取值，不能用公共默认静默替换生产设置**。`eps_s`、`eps_v` 由地类或外部发射率库给出；土壤发射率随含水量变化的关系与第 2.2 节同一组常数。

该式是发射率的输入构造，不是反演结果：它把 LAI 与发射率库的误差直接传递到 LST，产品 QA 必须标出 LAI 与发射率的来源。

### 15.4 组分温度反演的线性系统（当前实现）

在辐射域记四个组分的黑体辐亮度为 x = [B_λ(Tss), B_λ(Tsh), B_λ(Tls), B_λ(Tlh)]，则每个观测（角度或波段）是它们的线性组合：

```text
y = A x,     A[j, k] = eps_k * P_jk
```

`P_jk` 是第 j 个观测下第 k 个组分占的辐射权重，由 `hom3` 节点辐射度（四种组分比例 + 多次散射）给出。2 组分和 3 组分模式是把两土壤或两叶片按权重合并，公式不变、只是列数减少：

| 组分数 | 组分定义 |
|---|---|
| m = 2 | 土壤（Tss + Tsh 合并）、植被（Tls + Tlh 合并） |
| m = 3 | 光照土壤、阴影土壤、植被（两叶片合并）；或光照土壤、阴影土壤 + 植被、按案例约定 |
| m = 4 | Tss、Tsh、Tls、Tlh 全部保留 |

求解与质量门槛：

```text
加权：A~ = A / sigma，y~ = y / sigma；sigma 为观测辐亮度标准差
OLS：x_hat = argmin || A~ x - y~ ||^2
ridge：x_hat = (A~^T A~ + lambda I)^-1 A~^T y~，lambda = 0 时退化为 OLS
T_k = B_lambda^-1(x_hat_k)
```

- 有效观测数小于组分数 → `INPUT_INVALID | RETRIEVAL_FAILED`；
- `cond(A~) > 1e6` → `ILL_CONDITIONED | RETRIEVAL_FAILED`；该判断先于 ridge，ridge 不救已判奇异的矩阵；
- 任一 `x_k ≤ 0` → `OUT_OF_RANGE | RETRIEVAL_FAILED`；
- 逆 Planck 后任一温度超出 200–380 K → 该像元全部置 NoData 并标记 `OUT_OF_RANGE`。

必须注意：正值与温区检查是**求解后过滤**，不是有界最小二乘。也就是说，返回的解不是“在物理约束下最优”，而是在无界解恰好物理时的结果。`residual_rms` 记录的是未加权的原单位辐射残差，不是目标函数值，也不是 K 尺度的 RMSE。

### 15.5 欠定情形：窗口、先验与约束（当前实现，案例级）

观测数少于组分数时，四个温度不能逐像元独立求解。当前实现提供三类补充信息：

**空间窗口。** 假设窗口内组分辐亮度局部常数，把 s×s 窗口的 N 个角度展平成 s²N 个方程，共用同一组 x：

```text
[y_1; y_2; ...; y_s2N] = [A_1; A_2; ...; A_s2N] x
```

窗口内 A 仍逐像元变化（地表结构与角度不同），因此方程秩由空间变化补足。边缘用不完整窗口，中心观测本身无效时也可由邻域给出结果——这既是优点也是风险：没有最少有效像元比例、中心有效性或空间相似性检查，异质窗口会把两个地块的温度混成一个解。

**先验与正则化。** 形式为 Tikhonov 或高斯 MAP：

```text
Tikhonov：min || A x - y ||^2 + lambda || x - x_b ||^2
Gaussian MAP（以 300 K 为中心、温度先验标准差与相关系数给定、噪声方差由 d B / d T 换算）
  Q = A^T A / sigma^2 + C0^-1
  x_hat = Q^-1 ( A^T y / sigma^2 + C0^-1 mu )
```

这是 MAP/Laplace 风格的近似：给出点估计和（若保留 Q）后验协方差，但不是后验采样，也没有 credible interval。

**物理约束。** 用 SLSQP 求距离加权残差平方和最小，约束写成 g(x) ≥ 0：

```text
max(x) >= max(B(LST))，组分辐亮度包住中心观测黑体辐亮度
min(x) <= min(B(LST))
-d_min <= x_i - x_j <= d_max，相邻组分温差上下限
```

温差约束实际实现为 B_λ(T_mean + d/2) - B_10.8(T_mean - d/2)，是以平均温度 T_mean 为参考的辐射差近似，不是精确的 B^-1(x_i) - B^-1(x_j)；λ ≠ 10.8 μm 时存在系统偏差。包络约束的 `max/min` 使可行域非光滑且可能多分支。历史实现还存在不检查优化 `success/status`、查询后不重算其他分量等问题，使用时必须把收敛状态写入产品。

### 15.6 STREAM 内建同化：可微算子与 MAP 分析（当前实现）

**运行方式。** 工作台只区分“直接模拟”和“同化”。同化的观测有三类：亮温（每个热红外波段一个观测，可加其他视角）、地表温度（按地类固定发射率归一的 LST，10.5 μm）、组分温度（Tss/Tsh/Tcs/Tch）。实现见 `models/stream/app/assimilation.cpp`；观测误差、背景误差与迭代参数是该文件中的固定默认值，不在界面暴露。发射率不作为控制变量。

**控制变量。**

| 背景 | 控制变量 x | 组分温度 |
|---|---|---|
| RT（给定组分温度） | Tss、Tsh、Tcs、Tch | 即控制变量 |
| EB（ERA5 能量平衡） | 土壤水分 θ、Vcmax25 | 由能量平衡解 T(x) 给出 |
| 任一背景 + 光学反射率观测 | 追加 LAI | — |

**观测算子就是正向成像。** 热红外与成像共用 `thermalPixel`（`app/thermal_view.cpp`），包括面元坡面几何与山包/山脊复合面元：

```text
L_j = Σ_k w_jk(LAI, ε_s(θ), θv_j, φv_j, θs) · B(λ_j, T_k)
w_jk = 四组分比例_k(LAI) · 组分发射率_k + hom3 多次散射项_k
y_j = B⁻¹(λ_j, L_j + (1 − Σ_k w_jk) · B(λ_j, T_sky))   亮温（含反射天空，T_sky = (L↓/σ)^¼）
y   = B⁻¹(λ, L / Σ_k w_k(ε_fix))         地表温度（固定发射率约定，不含天空项）
y_k = T_k                                组分温度
ρ_b = canopyReflectance(LAI, ρ_leaf, ρ_soil(θ), geometry, diffuse)   光学
```

L↓ 由背景状态一次确定（来源见 0.2 节“STREAM 2026-11-20 修正”），迭代中不随后验温度重算，反演/同化与其结果的正向图像为同一算子。

**可微算子（预存在模型中）。** 物理核（`physics/canopy`、`radiosity`、`shortwave`、`energy`、`heat_conduction`、`soil_emissivity`、`brightness`）都是标量类型模板：正向模拟用 `double`，同化用 `Dual<8>`（`physics/dual.h`，前向自动微分）运行同一份代码，得到四组分比例、hom3 5×5 求解、土壤含水量/Hapke 发射率、Planck 与冠层反射率对 x 的精确导数。导数的公式在编译时固定，数值随每个像元的状态在运行时算出。分支与限幅按当前值取活动分支的导数。BSM 土壤反射率对 θ 的导数取 1/1000 网格上相邻两格的差商。

**EB 背景：收敛点隐式微分。** 过境时刻四组分能量平衡残差（Rn − H − LE − G）在收敛点满足 R(T, x) = 0，因此

```text
dT/dx = −(∂R/∂T)⁻¹ ∂R/∂x,      H = ∂h/∂T · dT/dx + ∂h/∂x
```

∂R/∂T 与 ∂R/∂x 由同一次对偶数残差计算得到（`energyResiduals<Ad>`），每像元一次 4×4 求解（无叶片时 2×2）。θ 通过土壤发射率、土壤表面阻抗（Sellers 选项）、Johansen 热惯量（含水量选项）与土壤短波反照率进入 R；Vcmax 通过 Farquhar/Ball–Berry 气孔阻抗进入；LAI 通过 hom3 辐射、组分比例与短波吸收进入。稳定度 1/L、阵风通量与过境前的土壤热历史在求导时冻结，非线性部分由 Gauss–Newton 每次迭代重新求解能量平衡来修正。

**MAP 分析（每像元）。**

```text
J(x) = Σ_j (y_j − h_j(x))² / σ_j² + (x − x_b)ᵀ B⁻¹ (x − x_b)
x_{i+1} = x_b + (Hᵀ R⁻¹ H + B⁻¹)⁻¹ Hᵀ R⁻¹ [ y − h(x_i) + H (x_i − x_b) ]
C_a = (Hᵀ R⁻¹ H + B⁻¹)⁻¹,   DFS = n − tr(C_a B⁻¹)
```

控制变量限制在物理范围内（温度 150–400 K，θ 0.02–0.60，Vcmax 5–250，LAI 0–10）；最大步长低于 1e-3 倍背景 σ 时收敛。EB 背景下组分温度的分析 1σ 按 gₖᵀ C_a gₖ 传播（gₖ = dTₖ/dx）。分析场随后替换本次成像的组分温度、土壤水分与 LAI，输出影像即分析场的正向图像。

| 默认值 | 取值 |
|---|---|
| 观测误差 σ_o | 亮温 0.5 K；地表温度 1.0 K；组分温度 2.0 K；反射率 0.02 |
| 背景误差 σ_b | 组分温度 5 K，组分间相关 0.5；θ 0.10 m³/m³；Vcmax 30%（≥ 10）；LAI 30%（≥ 0.5） |
| 迭代 | RT 最多 20 次，EB 最多 10 次（每次重解能量平衡） |
| 质量位 | 0 输入无效/无观测，2 越界或到达边界，3 失败，4 病态，8 DFS < 0.2，9 未收敛 |

**单独的温度反演（保留，`app/inversion.cpp`）。** 引擎配置的 `inversion` 块仍提供 LST（四组分同温加权 Gauss–Newton，发射率误差传播）与 LSCT（MAP，可选同地类 s×s 窗口）反演，导数由 Planck 链解析给出：dy_j/dT_k = w_jk B′(λ_j, T_k) / (d_j B′(λ_j, y_j))，d_j 对亮温取 1、对 LST 取 ε_fix。工作台不再单独列出，二者不能与同化同时使用。

角色分工：HiStream 提供三维场景与 OSSE 真值样本；STREAM 提供可微的 H(x) 与分析；STREAM-NET 只修正正向亮温残差，不作为物理反演器；LS4T 负责把卫星观测落成 LST/LSCT 产品，可直接作为“地表温度”“组分温度”同化的观测。

单像元原型（`tools/stream-inverse/`，亮温噪声 0.3 K）的数值证据：

| 量 | 结果 |
|---|---|
| autograd 梯度相对误差 | 7e-9 |
| LAI 误差（真值 2.5） | 0.04 |
| 四组分温度均值误差 | 约 1.3 K |
| 单组分温度 RMSE | 约 5.9 K |
| 观测 RMSE | 0.17 K |
| Jacobian 条件数 | 约 5.8e3 |

结论与 15.1 一致：LAI 与等效温度可识别，**单个晴/阴组分温度在单角度多波段亮温下不可独立反演**；同化中这表现为 DFS 接近 1、分析主要由背景决定。需要多角度、光学 BRF、时间序列或 EB 背景的物理约束，这不是优化器问题。
### 15.7 产品、质量与验证

产品分层沿用卫星产品的既有约定：

```text
L1O -> L2LST / L2LSCT -> L3N -> L3C -> L4A
```

L2LST 输出温度场、经纬度、QC 与不确定度；L2LSCT 按组分顺序输出温度、残差、条件数与 QC。规范化（角度/时间/空间/传感器）与降尺度分别手工执行，融合只接受已处于相同网格与归一化基准的 L3N 数据。

质量标记的语义必须与第 15.2、15.4 节一致：`INPUT_INVALID`、`CLOUD`、`OUT_OF_RANGE`、`ILL_CONDITIONED`、`RETRIEVAL_FAILED` 各自表示输入无效、云污染、结果越界、矩阵病态和求解失败，不能合并成一个“坏像元”计数。

**不确定度的现状必须显式声明。** LS4T 的 L2LST `uncertainty` 由调用者给定（默认为 1 K 填满），不是由残差或协方差传播，LS4T 的 LSCT 结果也没有组分后验标准差字段；STREAM 内建反演（15.6 节）则输出 LST 1σ 与 LSCT 后验标准差。用 LS4T 产品做“68% 覆盖率”保守性检验前须先补传播。

建议的精度目标（产品目标，不是当前原型已达标）：

| 产品 | 场景 | 目标 | 验证方式 |
|---|---|---|---|
| LST | 植被/农田/裸土 | RMSE ≤ 1.5 K，bias ≤ 0.5 K | 站点、UAV、跨传感器 |
| LST | 城市/异质像元 | RMSE ≤ 2.0 K | UAV、高分辨率航空 |
| LSCT 晴/阴土壤 | 多角度或强先验 | RMSE ≤ 2.5 K | UAV 多角度、组分温度观测 |
| LSCT 晴/阴叶片 | 多角度或强先验 | RMSE ≤ 3.0 K | UAV/站点、热像仪 |
| 不确定性 | 全部 | 68% 覆盖接近 1σ，晴空 QA 有效率 ≥ 95% | 覆盖率、可靠性图 |

反演验证以第 16.1 节的最低要求为下限，另外必须包含：OSSE（HiStream 样本加噪声后反演，与真值比较）；闭合检查（反演结果回代正向，残差应在噪声量级）；跨传感器一致性（统一发射率、大气与几何后比较）；图级偏差与空间结构（不出现椒盐噪声），不能只报点位 RMSE。

## 16. 数值验证与适用边界

### 16.1 最低验证要求

每次新增场景或算法至少进行：

1. 能量约束：反射、透射和吸收不超出 `[0, 1]`，面元/体元交换不凭空产生能量；
2. 极限场景：黑体、完全反射体、无遮挡平面、单体元和单面元；
3. 分辨率敏感性：逐步减小面元或体元尺度，检查输出是否趋于稳定；
4. 角度对称性：对称场景在对称方向应给出一致结果；
5. 模式交叉验证：同一简单场景比较 FacetRT 与 VoxelRT、FacetEB 与 VoxelEB；
6. 观测验证：统一时间、几何、大气、空间响应和波段响应后计算偏差、RMSE 和角度残差。
7. 碳同化检查：非植被 GPP/NPP 为 0，夜间 GPP 接近 0，日间 GPP 对有效光合辐射具有合理响应；
8. 周期边界检查：对平移周期场景比较 0 次与 1 次穿越，确认没有几何复制导致的能量重复计数。

### 16.2 结果解释边界

- Three.js 只负责场景预览，不代表实际计算精度；
- Three.js 大场景最多抽样显示 5000 个实例，结果文件仍保存全部有效体元；
- 局部计算域仅保留包围盒内几何，跨界对象的域外部分不会参与体元化或求解；
- FacetRT/FacetEB 启动前按“OBJ 多边形三角化数 × 实例数”预估展开规模；超过 `1,000,000` 个三角面将直接阻止运行，应分别切换到 VoxelRT 或 Voxel RT–EB；
- 影像分辨率、波段数、观测角数和过程输出共同决定连续数组大小；极端组合可能触发 `Array buffer allocation failed`，应先缩小输出规模，再评估场景复杂度；
- 图像 2%–98% 拉伸和 colorbar 只影响显示，不改变原始 GeoTIFF；
- 体元综合属性是尺度相关的，改变体元大小后应重新统计；
- 亮度温度不是物理温度的线性平均；
- 简化流体、水体和火焰模块服务遥感正向模拟，不等同于专业 CFD、水动力或燃烧模型；
- 当前 GPP/NPP 为瞬时叶面积尺度输出，其中 NPP 是叶片净同化近似，不等同于严格生态系统 NPP；
- LUT 大气适合覆盖节点内插值，超出节点范围不应外推解释；
- 论文中的解析模型、核模型、自动微分和深度学习代理属于扩展方向，除本手册明确标注外不代表当前已实现。
