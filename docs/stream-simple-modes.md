# STREAM 简化正向模式：RT / EB 各一个

状态：输入契约草案（2026-10-27）。目标是压掉模式矩阵和难获取参数：每个参数只有“常数/栅格文件/默认值”三种来源，叶倾角固定球形，大气固定一种。

## 1. 原则

- 只保留 **一个 RT 模式**、**一个 EB 模式**；
- 参数来源只有：常数、栅格文件、默认值；
- 叶倾角分布固定为球形，不要求 LIDF；
- 大气固定一种预设，不要求用户给廓线；
- 土壤水分可以是一个值，也可以是文件；
- 拿不到的参数用默认值，并标记 QA，不阻塞运行。

## 2. RT 模式（组分温度已知）

| 类别 | 输入 | 来源 | 默认/说明 |
| --- | --- | --- | --- |
| 结构 | LAI | 常数或栅格 | 必填；没有则按地类给默认 |
| 森林结构 | 森林高度、森林密度 | 常数或栅格 | 可选；用于有效 LAI/gap |
| 叶倾角 | 球形 | 固定 | 不输入 LIDF |
| 组分光谱 | 叶片反射率/透射率、土壤反射率 | 默认库或文件 | 默认按 PFT/土壤类型 |
| 组分温度 | Tss/Tsh/Tls/Tlh | 常数或 4 波段文件 | 必填（RT 的核心输入） |
| 观测角 | VZA/VAA | 常数或栅格 | 固定值或逐像元 |
| 太阳角 | SZA/SAA | 常数或栅格 | 固定值或逐像元；不给则由时间/经纬度算 |
| 地形 | 单一坡：逐像元一个坡度/坡向；面元法：30/10 m 细面元逐个算；山包/山脊：像元内几何体 + 密度 | 常数或栅格 | 可选；默认平地；详见 [terrain-methods.md](terrain-methods.md) |
| 大气 | 一种预设 | 固定 | 默认中纬度夏季/乡村气溶胶 |
| 土壤水 | 一个值或文件 | 常数或栅格 | 影响发射率/热红外 |
| 波段 | 中心波长/带宽/SRF | 传感器预设 | 默认 Landsat 8/9 或通用 VNIR+TIR |

输出：BRF、方向亮温、组分亮温、LST/LSCT（由组分温度与比例合成）、QA。

## 3. EB 模式（温度由能量平衡求解）

与 RT 相同的结构、森林、地形、观测角、太阳角、大气、土壤水、波段输入，另外：

| 输入 | 来源 | 说明 |
| --- | --- | --- |
| ERA5 年度包 | 文件 | 逐时气象驱动 |
| 初始温度 | 默认/文件 | 默认首日平均气温 |
| 土壤热参数 | 地类默认 | 可覆盖 |
| 土壤水分 | 一个值或文件 | 与 RT 相同 |

输出：四组分温度、LST/LSCT、方向亮温、净辐射/显热/潜热/土壤热通量、QA。

注意：EB 模式下组分温度是**输出**，不能当输入；RT 模式下才是输入。

| 一种大气预设 | 未接入；需定预设参数与接口 |
| 波段/SRF | 已有波段配置，需确认 SRF 处理 |

## 5. 必须先定义的三件事

1. **森林密度**：是覆盖率（0–1）还是株密度（株/m²）？前者直接给 gap/cover，后者还需要冠幅/冠形。
2. **山包/山脊复合坡**：定义为“像元内几何体 + 密度”的统计分布，具体见 [terrain-methods.md](terrain-methods.md)；不再使用“圆锥姿态”这一含糊说法。
3. **大气预设**：中纬度夏季/乡村/能见度 23 km 是否够？只做 TIR 透射/上行/下行辐射，还是也做光学？

这三点定了，RT/EB 两个模式的输入契约就可以冻结，不再增加必填项。
