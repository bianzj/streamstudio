# StreamSim 1.1.4 — Mesh 镜面反射

> 历史发布说明，保留当时的 StreamSim 名称；当前产品名为 Stream Studio。

基于本地 1.1.3 修复版本的小版本更新。工程格式仍为 schema 6。

## 使用方法

- 在“材质属性 → 光谱特征”中设置镜面比例和粗糙度。
- 在“场景对象 → 属性 → 编辑 OBJ 计算属性”中，为每个 Mesh 单独选择“使用镜面反射”。共享同一材质的 Mesh 可以分别开启、关闭。
- 数值随材质保存，开关随 Mesh 保存；支持 JSON 保存加载及界面 XML 导入导出。旧工程按原有效设置迁移，不会自动给原漫反射表面添加高光。
- 在“分析 → 角度分析”中查看短波反射率。图中同时显示太阳主平面、垂直主平面，悬停可查看实际观测天顶角和方位角。

## 模型边界

- 镜面反射仅支持简单光线追踪（eRaytracing）的短波计算（≤2500 nm），覆盖太阳直射、天空散射和多次表面反射。其他求解器遇到启用的非零镜面项会明确报错。
- 使用能量受限的经验 modified-Phong 模型，将既有反射预算分配给漫反射项和镜面项；不是基于实测折射率的 Fresnel 玻璃模型。粗糙度需要按具体组件的 BRDF 标定。
- 镜面方向由太阳方向和表面法线共同决定；有限宽度的高光瓣可同时出现在两个观测平面的截线上。
- 科学影像保留可能超过 1 的方向反射因子。该值不等于半球积分反射率，热红外参数及热发射不受此开关影响。
- 中央三维视图是几何/纹理预览，不显示上述物理镜面高光。计算影像和角度曲线包含阴影、遮挡及反射的综合作用；当前曲线为整幅均值，未单独分解阴影或镜面分量。
