# StreamSim 1.1.2

- VoxelEB 的直接、漫射 PAR 统一使用 `μmol photons m⁻² leaf s⁻¹`；默认生化方法移除原有乘 1000 补偿，Farquhar 接收正确绝对量级。
- VNIR 加速分组在 700 nm 边界分开，直接和漫射使用一致中心及实际组宽。
- VoxelEB 短波按配置的直射/漫射比例归一化各自光谱，包含纯直射和纯漫射边界；端点积分权重与 GPU 求和一致。
- VNIR 短波散射支持配置 1–3 阶（默认 1 阶）；2/3 阶使用逐阶散射路径，包含天空漫射，并输出逐阶诊断。
- 两个现行 LBM 流体着色器补齐 RayQueryKHR 能力声明；构建清理五份已删除的旧流体着色器，防止增量复制将旧二进制再次带入安装包。
- 两套生化方法使用稳定二次根，保护零光照、零湿度、零 CO₂ 等边界。Farquhar 使用材料的 kV/stressfactor，保留 THETA=0 的严格线性极限。
- 非法输入、不可表示值或真正无实根保留缺测，由引擎输出诊断并以非零退出码结束；不截断异常值来伪造有效结果。
- 每个 VoxelEB 节点写入 `diagnostics/physiology_node=*_T=*.json`，检查温度、辐射、热通量、碳通量、PAR 和表面阻力。即使关闭过程导出也执行检查；打开能量过程时另存浮点诊断字段；火焰/雾等参与介质排除叶片生理统计。原过程二进制布局保持兼容。
- `npp` 保留兼容字段 ID，显示为叶片净同化（Ag−Rd），不表示包括茎根呼吸的整株 NPP。
- 气象输入严格解析数字、支持空白与单节点文件；入射光谱检查长度、有限值和非负性；文本分隔不再丢失单字符尾字段。
- Stream3D 适配独立 runId/outputDir，温度及应用分析读取该运行的冻结工程和气象，校验 SHA256，拒绝错配和损坏的输入。

验证使用提取的实际生产代码、float32 数值回归和小型原生 GPU 场景。该验证检查实现与接口，不构成实测精度验证；高温极低 CO₂ 下无实根等超出求解支持域的状态会明确失败。吸收光子换算仍保留历史 AHC 常量，其与精确 SI 常量的差约 0.0712%。
