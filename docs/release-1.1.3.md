# StreamSim 1.1.3

本版为全模型审阅后的缺陷修复版本，不改变工程文件格式（schema 6），SCOPE 1.73 与 SCOPE 2 两个能量平衡回归均通过。

## 模型

- RayTracing：射线起点在实例变换下被重复变换、实例法线按转置变换，导致平移或旋转后的 OBJ 实例在第二次反弹起反射/透射侧判断和 Hapke 角度权重错误，已修正。
- RayTracing：部分波段透射率为 0 的材质改为所有波段共用一次反射/透射选择；无热数据时温度描述符仍完整绑定；纹理因子偏移改为无符号并检查 GPU 存储缓冲上限。
- FacetEB / FacetRT：开启周期边界时，面元与自身周期副本之间的互照不再被丢弃（CPU 与 GPU 一致）；光谱图像与能量求解使用同一法向直射换算。
- VoxelEB：城市气动阻力不再退化为常数 150 s/m；rss 有确定初值；每个节点的叶面水汽压与 CO₂ 从当前节点大气值起算；`es` 出现无效值后不再自锁。
- 太阳位置时刻在 FacetEB 与体元模式中统一按秒四舍五入（原为截断到分钟）。
- 引擎每次运行不再向固定的 `C:\work` 路径建目录（无该目录的机器上会启动失败）。

## 输入与几何

- 实例位置文件统一解析：支持空格、Tab、逗号分隔，跳过注释与空行，CRLF 文件不再产生 (0,0,0) 处的多余实例；缺列逐行补默认值；文件缺失时报错。
- RayTracing 中没有位置文件的对象放在场景中心（与 FacetRT 一致）；同名 OBJ 分组全部加载。
- RayTracing 的 DEM 处理 nodata、修正行列分辨率、读取失败时报错。
- 反射率纹理支持 alpha、调色板与 16 位图像；墙面纹理不再上下颠倒，地面纹理按北上东右。
- `dTime ≤ 0`、短波散射阶数超出 1–3、体元模式光谱名不存在时直接报错；`control.gpu` 生效并检查越界。
- 导入 DEM：修复 LZW 压缩 TIFF 解码失败与 Predictor 2/3 数值错误。

## 界面与服务

- 保存后继续在属性面板修改的值不再丢失；空输入框不再被当作 0；切换工程时清空纹理缓存；补全英文界面文本。
- 工程内保存的外部文件路径在 Windows 上正确判断为工程外，另存为后引用不再断开。
- “删除全部结果”覆盖各次运行目录；运行前后校验冻结的工程与气象快照。
- 运行接口只接受内置引擎；自定义引擎路径需加入环境变量 `STREAMSIM_ENGINE_ALLOWLIST` 后重启。
- 重置只结束本程序启动的引擎进程。

## 行为变化

- 自定义引擎、`control.gpu`、无位置文件的 RayTracing 对象、物理纹理朝向的变化见上文；依赖旧行为的工程需要检查。
