# 图5 站点足迹示例

图5  站点周边CO2与H2O潜在来源区的日内变化示例。黄、橙、紫线分别表示50%、80%、90%的累积输送权重；地形底图用于展示来源区位置。

这个例子说明，站点接收到的通量来自上风向一定范围的区域。随着风向和大气稳定度变化，潜在来源区的方向、形状和覆盖范围也会改变。图中四个时段的来源区主要朝向西北至偏北。

图3的中心2×2 km是局地空气温度与风场的展示窗口；图5则把视野扩展到站点上风向，说明通量测量的代表区域与局地模拟窗口之间的关系。两张图展示不同功能，不必采用相同的地图范围。

CO2和H2O在相同输送条件下共用足迹核；实际碳、水通量还取决于来源区的植被、土壤及其他源汇。这里作为功能演示，不用于评价站点选址优劣。

图5沿用2019-08-17的FFP情景结果；其他图沿用各自结果，未重新计算。
