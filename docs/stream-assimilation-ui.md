# STREAM 正向 / 同化选择设计

状态：交互设计草案（2026-10-27）。目标是用“选变量”代替“选作业模式”：不选就正向模拟，选了就做 loss 最小的同化/迭代反演。

## 1. 一句话规则

- **不选目标变量、也不选同化观测**：用背景场直接正向模拟。
- **选了目标变量和同化观测**：以背景场为先验，最小化观测失配，做同化/迭代反演。
- 只选一边：仍可正向模拟，并给出提示或残差对比，不强行反演。

## 2. 先统一术语（避免“目标/同化”歧义）

建议界面用三句话，而不是两个抽象词：

| 界面名 | 含义 | 例子 |
| --- | --- | --- |
| **要得到的结果** | 反演输出的目标变量 | LST、LSCT、LAI、土壤水分 |
| **用来约束的观测** | 参与 loss 的卫星观测 | TIR 亮温、光学反射率、LST 产品 |
| **允许调整的量** | 优化器实际调整的控制变量 | 由目标自动映射，专家可改 |

如果保留“目标变量 / 待同化变量”的叫法，建议加一行小字：

- 目标变量 = 要反演/输出的量；
- 待同化变量 = 用来约束的观测；
- 控制变量默认自动映射，不要求用户理解。

## 3. 界面结构

```
模拟方式
  ○ 正向模拟（背景场）
  ● 同化 / 迭代反演        ← 由选择自动切换，不单独做“作业模式”

要得到的结果
  [ ] LST
  [ ] LSCT：Tss / Tsh / Tls / Tlh
  [ ] LAI
  [ ] 土壤水分
  [ ] 发射率

用来约束的观测
  [ ] TIR 亮温（按波段/角度）
  [ ] 光学反射率（按波段）
  [ ] LST 产品
  [ ] LAI 产品
  [ ] 土壤水分产品

背景场：当前工程输入 / EB 结果 / 气候态（只读，显示来源）
损失：观测失配 + 背景约束 + 空间/时间平滑
[ 运行 ]
```

交互要点：

- 两个列表都是**多选**，不是自由文本；
- 选择后顶部自动出现一句话摘要：
  - “用 Landsat B10/B11 亮温反演 LST，背景场来自当前工程。”
- 没有选择时，运行按钮就是“正向模拟”；
- 两个列表都有选择时，按钮变为“同化反演”，并显示迭代设置（默认折叠）；
- 只选目标、没选观测：提示“没有观测，只能正向输出目标变量”；
- 只选观测、没选目标：提示“只做正向模拟和残差对比，不反演”。

## 4. 行为矩阵

| 目标变量 | 同化观测 | 行为 |
| --- | --- | --- |
| 无 | 无 | 背景场正向模拟，输出全部标准产品 |
| 有 | 无 | 正向模拟 + 输出目标变量，提示缺少观测 |
| 无 | 有 | 正向模拟 + 观测残差/对比，不优化 |
| 有 | 有 | 以背景场为先验，最小化 loss，输出后验目标变量 + 不确定性 |

## 5. 背景场与 loss

背景场不是另做一个模式，而是当前工程输入的“先验状态”：

- 来源：当前 LAI/温度/土壤水分/EB 结果/气候态；
- 每个控制变量都有背景值 `x_b` 和背景误差 `σ_b`；
- loss 写成用户能看懂的三项：

```
loss = 观测失配 + 背景约束 + 平滑约束
```

- 观测失配：模拟观测与卫星观测的差，按观测误差归一化；
- 背景约束：反演值不要离背景场太远；
- 平滑约束：空间/时间不要出现椒盐噪声；
- 高级设置里才露出权重、误差、迭代次数。

## 6. 变量目录（首版）

### 目标变量

| 变量 | 单位 | 控制变量（自动） | 可识别性 |
| --- | --- | --- | --- |
| LST | K | 像元等效温度 | 单/双 TIR 波段可行 |
| LSCT | K（4 组分） | Tss/Tsh/Tls/Tlh | 单角度单波段欠定，需多角度/多时相/先验 |
| LAI | m²/m² | LAI | 光学反射率可行；TIR 单独不可行 |
| 土壤水分 | m³/m³ | 土壤水分 | 光学/微波更可行；TIR 弱 |
| 发射率 | 每波段 | 波段发射率 | 多波段 TIR 才可识别 |

### 同化观测

| 观测 | 来源 | 适合目标 |
| --- | --- | --- |
| TIR 亮温（单/双波段） | Landsat/SLSTR/MODIS | LST、LSCT |
| 多角度 TIR 亮温 | SLSTR 双视角/UAV | LSCT |
| 光学反射率 | Sentinel-2/Landsat | LAI、结构约束 |
| LST 产品 | 外部产品 | LST 同化/交叉验证 |
| LAI 产品 | 光学产品 | LAI 同化/结构先验 |
| 土壤水分产品 | SMAP/ERA5 | 土壤水分同化 |

## 7. 预设（降低选择成本）

不要要求用户从零组合；提供 3–5 个预设，选择后自动勾选变量：

- **LST 单景**：目标 LST；观测 TIR 双波段；控制等效温度；
- **LSCT 多角度**：目标 LSCT；观测多角度/多波段 TIR + 光学；控制四组分；
- **LAI 光学**：目标 LAI；观测光学反射率；控制 LAI；
- **LST + LAI 联合**：目标 LST/LAI；观测 TIR + 光学；控制温度 + LAI；
- **只做正向**：全不选。

预设只是勾选组合，不是新增“作业模式”。

## 8. 结果页

同化运行后输出：

- 后验目标变量场；
- 1σ 不确定性；
- 观测残差图；
- 背景场与后验的差值；
- 收敛状态、迭代次数、cost 分量；
- QA：云/水/饱和/不收敛/低置信度。

正向运行则输出常规模拟产品，不显示后验/残差。

## 9. 需要确认

1. “目标变量 / 待同化变量”是否按上面的定义：目标是结果，同化是观测？如果“待同化”指被调整的量，需要把名字改成“控制变量”。
2. 首版目标变量是否只放 LST、LSCT、LAI、土壤水分、发射率，还是只放 LST/LSCT？
3. 观测是否只支持 TIR 亮温 + 光学反射率，还是也接外部 LST/LAI 产品？
4. 背景场默认用“当前工程输入”还是“上一次 EB 结果”？
