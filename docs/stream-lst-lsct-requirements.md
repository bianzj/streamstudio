# STREAM 反演需求：LST 与 LSCT

状态：需求草案（2026-10-27）。反演目标限定为 **LST（Land Surface Temperature，地表温度）** 与 **LSCT（Land Surface Component Temperature，组分温度：Tss/Tsh/Tls/Tlh）**；LAI、土壤水分、发射率、大气等作为输入/先验，不作为本轮反演变量。精度指标为建议目标，需用实际验证数据确认。

落地状态（2026-10-30）：反演算法由 **LS4T**（`C:\work\ls4t`）承担，它的定位就是为 HiStream 与 STREAM 的同化提供 LST/LSCT 产品、角度/时间/空间归一化与降尺度链条；本文的方法已分别写入[模型理论手册第 15 章](theory-manual.md#15-地表温度与组分温度反演)与[模型使用手册 5.3 节](user-manual.md#53-地表温度与组分温度反演lst--lsct)，数据契约与已知缺口见 [lst-lsct-inversion.md](lst-lsct-inversion.md)。Stream Studio 引擎与工作台已内建以 STREAM 正向模型为观测算子的同化（“运行方式”：直接模拟 / 同化亮温、地表温度、组分温度；`assimilation` 配置块；RT 背景更新四组分温度，EB 背景更新土壤水分与 Vcmax，有光学观测时更新 LAI，雅可比由模型内置的对偶数可微算子给出），单独的 LST / LSCT 反演保留为 `inversion` 配置块（见 lst-lsct-inversion.md 第 6 节）。

## 0. 分工前提

- **TiRT / TIRTEB**：单点/单像元的正向与反演算法研究、参数敏感性、算法验证；单点工作已经在这里开展，STREAM 不重复实现一套单点模型。
- **HiStream**：三维场景的高保真正向模拟与样本生成；STREAM-NET 在其亮温结果上做前向残差修正。
- **STREAM**：把 TiRT/TIRTEB 验证过的单点算法扩展到**整景影像**，负责栅格 I/O、逐像元并行、空间约束、邻域/大气/几何配准、批量与时序、QA/不确定性、产品与界面。
- `tools/stream-inverse` 的单像元原型只用于梯度校验和数值对照，不作为 STREAM 的产品形态。

因此，STREAM 的需求重点不是“再做一个单点反演器”，而是“影像级反演产品”：同样的物理，加上空间、传感器、工程和产品约束。

## 1. 产品定义

### 1.1 LST

- 定义：传感器观测方向上的像元等效辐射温度（方向性 LST），单位 K；
- 输出：`lst.tif`（K）、`lst_uncertainty.tif`（1σ, K）、`lst_qa.tif`；
- 说明：LST 是像元尺度等效温度，不等于任一组分温度；需记录观测天顶角/方位角、发射率来源、大气订正来源。

### 1.2 LSCT

- 定义：像元内四个组分的温度：Tss（光照土壤）、Tsh（阴影土壤）、Tls（光照叶片）、Tlh（阴影叶片）；
- 输出：`lsct.tif`（4 波段，K）、`lsct_uncertainty.tif`（4 波段，1σ）、`lsct_fractions.tif`（可选，四组分比例）、`lsct_qa.tif`；
- 说明：LSCT 是“组分温度”，不是 LST 的简单分解；必须同时给出组分比例或假设，否则温度不可解释。

### 1.3 LST 基线：分裂窗（默认方案）

如果目标只是 LST，**分裂窗（split-window, SW）就是正确基线**，不需要可微同化：

- 输入：两个 TIR 波段亮温、发射率、大气水汽（或可降水）、观测天顶角；
- 输出：LST（K）+ 误差传播；
- 优点：成熟、快、可业务化、系数可按传感器标定；
- 局限：
  - 需要两个热红外波段；只有单波段时只能做单通道 + 大气校正；
  - 发射率/水汽误差直接进入 LST；
  - 城市/异质像元得到的是等效辐射温度，不是组分温度；
  - Landsat 8/9 B11 存在杂散光/定标问题，需按 USGS 建议选择单波段或 SW，并做 QA。
- STREAM 在 LST 产品中的角色：实现 SW、发射率/水汽/云掩膜/QA、误差传播、批量与时序，不是可微反演。

**LSCT 不能靠分裂窗**：SW 只给一个等效温度，无法分离 Tss/Tsh/Tls/Tlh。LSCT 才需要多角度/多时相/先验 + 可微反演；SW 的 LST 可作为 LSCT 的等式约束或初值。

| 观测几何 | 必需 | VZA/VAA；多角度数据需逐角度；LST 定义依赖观测方向 |

| 云/QA | 必需 | 云掩膜、饱和、阴影、水体、雪；用于 QA 与剔除 |

| DEM | 可选 | 高程订正、地形/坡向；山区必需 |
| ERA5 | 可选 | 若用 EB 约束或时间同化则需要；纯 TIR LST 反演可不用 |
| 时间 | 可选 | 时间序列同化/多时相时需要 |

### 2.1 RT 与 EB 的输入区别

- **RT 模式**：组分温度是输入（Tss/Tsh/Tls/Tlh 或文件）；组分光谱是输入或由 PROSPECT/BSM 模拟；输出 BRF、方向亮温、组分亮温。
- **EB 模式**：组分温度是**输出**，由 ERA5/气象、土壤水分、初始温度和 LAI/结构/光谱共同求解；不能把组分温度当输入（只能给初值）。
- 因此“组分温度（输入或文件）”只适用于 RT 正向测试；EB 正向测试的输入是气象与地表参数。

### 2.2 森林结构与地形（当前实现边界）

**森林结构**

- “森林高度 + 森林密度”不足以驱动冠层辐射传输；还需要冠形/冠幅、覆盖度、聚集指数、叶倾角分布，才能确定 gap 概率和光照/阴影比例。
- 当前 STREAM 实际使用的是：LAI（栅格）、冠层高度、叶宽、叶投影（G）、热点；**均匀冠层 + 球面叶倾角**。
- 代码里有 `treeStand`（株/m²）、`canopyHeight`、`crownShape` 和 `effective_lai.cpp` 的冠层/行结构 gap 计算，但**尚未接入配置和成像主流程**；目前不会因为填了森林密度就自动改变结果。
- 要真正“考虑森林结构”，最小改动是把株密度/冠形/高度接入有效 LAI 与方向 gap；完整三维结构仍需 HiStream 或多层模型。

**地形**

- 只有坡度、坡向不够；还需要 DEM、天空视角因子、地形遮挡/阴影、局部入射角。
- 当前 STREAM 的 DEM 只用于高程订正（气温/气压）和太阳位置，**没有做坡面辐射传输、地形阴影或天空视角**；坡向/坡度输入目前不会自动进入 RT。
- 若要做地形，需要明确：局部太阳/观测几何旋转、直散比、天空视角、邻坡遮挡，以及是否做邻像元 adjacency。

### 2.3 输入分级：不要把“模型需要”当成“用户必须提供”

模型内部需要很多参数，但用户不应该被要求全部提供；否则模型无法应用。原则：

- **能派生的派生**：坡度/坡向从 DEM 算，发射率从 NDVI/ASTER 算，大气从 ERA5/LUT 算；
- **能默认的默认**：叶片/土壤光谱按 PFT/纹理给默认值，聚集指数/叶倾角按文献 PFT 默认；
- **拿不到的给先验 + 不确定性**：森林高度/密度、组分温度、土壤纹理等，允许缺省，并把不确定性传播到产品；
- **只有影响可识别性的参数才强制**：观测波段、几何、云掩膜、LAI/地类、气象（EB）。

| 级别 | 用户提供 | 软件默认/派生 | 适用 |
| --- | --- | --- | --- |
| L0 最小 | 卫星 TIR/光学波段、观测几何、云掩膜、LAI/地类、ERA5 | 发射率、大气、叶片/土壤光谱、结构、土壤水分、地形 | 一键跑、应用默认 |
| L1 标准 | L0 + 发射率/大气产品 | 结构/光谱默认 | 提高精度 |
| L2 高级 | L1 + 森林高度/密度、聚集指数、叶倾角、土壤纹理 | — | 研究/验证/专项 |

**难获取参数的处理**

| 参数 | 默认/替代 |
| --- | --- |
| 叶片光谱/性状 | PFT 光谱库或 PROSPECT 性状默认值 |
| 土壤光谱 | 按土壤纹理/颜色分类的 BSM 默认 |
| 发射率 | NDVI 阈值法、ASTER/JPL 库 |
| 大气 | ERA5/再分析或 MODTRAN LUT |
| 森林高度/密度 | GEDI/ICESat-2/SAR；没有则 PFT 异速生长关系，标记为默认 |
| 聚集指数/叶倾角 | 文献 PFT 默认，不要求用户逐像元给 |
| 土壤水分 | ERA5/SMAP/气候态 |
| 组分温度 | RT 模式可由 EB 或 LST 分配先验；不强制用户给四组分 |
| 坡度/坡向 | 从 DEM 自动派生 |

**产品必须标记输入等级**：用了哪些默认、哪些实测、哪些缺省；默认值越多，不确定性和 QA 等级越保守。不能在用户不知情时把默认值当真值。

**界面**：默认“基础模式”只露出 L0 输入；高级参数放“专家模式”，并提供“恢复默认”。预设按应用组织（Landsat LST、森林 LSCT、农田、城市），而不是让用户从 30 个参数里自己拼。

## 3. 可识别性与模式

| 模式 | 观测 | 未知量 | 可行性 |
| --- | --- | --- | --- |
| LST 单波段 | 1 个 TIR 波段、单角度 | 1 个温度 | 可行；依赖发射率与大气 |
| LST 分裂窗 | 2 个 TIR 波段、单角度 | 1 个温度（+固定 ε） | **推荐基线**；快、成熟，依赖 ε 与水汽 |
| LSCT 单角度 | 单/多 TIR 波段 | 4 个组分温度 | **欠定**；必须加先验/温度关系/光学约束 |
| LSCT 多角度 | 2+ 观测角度、多波段 | 4 个组分温度 | 可改善；仍可能病态，需正则化 |
| LSCT 多时相 | 多时次 TIR | 4 组分温度轨迹 | 可结合 EB/时间平滑，适合同化 |

结论：**LST 用分裂窗作为产品基线；LSCT 才需要可微反演**。LSCT 必须明确“靠什么信息分离四个温度”，不能只在单角度单波段上宣称可反演。

## 3.1 影像级新增需求（STREAM 与 TiRT/TIRTEB 的区别）

单点算法由 TiRT/TIRTEB 负责；STREAM 必须额外解决：

1. **逐像元并行与分块**：整景分块、重叠边界、断点续跑、内存上限；
2. **空间约束**：MRF/TV/分割/地类先验，避免逐像元独立反演产生椒盐噪声；
3. **邻域效应**：TIR 传感器 PSF、城市/异质像元的邻像元辐射混合（adjacency），不能只用单像元；
4. **几何配准**：多角度（SLSTR 双视角）、多时相、多传感器之间的重采样与配准误差；
5. **传感器模型**：SRF、PSF、噪声、饱和、条带；不能把 L1 辐亮度当理想值；
6. **大气空间变化**：逐像元水汽/气溶胶或分块 LUT，不用单点大气；
7. **QA/不确定性图**：逐像元 1σ、云/水/雪/饱和/不收敛标记；
8. **批量与时序**：场景列表、时间范围、任务队列、结果目录规范；
9. **图级验证**：除点位 RMSE 外，还要有图级偏差、空间结构、交叉传感器一致性。

这些是 STREAM 相对于单点模型的核心工作量，也是产品价值的来源。

## 3.2 植被结构特征

植被结构决定 gap 概率、光照/阴影比例、组分温度分配和方向亮温，是 LST/LSCT 反演能否成立的关键输入。

**结构参数**

- LAI、覆盖度、冠层高度；
- 叶宽、叶倾角分布（LIDF）、聚集指数/ clumping；
- 热点参数、垂直 LAI 廓线、光照/阴影组分比例。

**STREAM 当前表示**

- 均匀冠层（hom3）：LAI 来自栅格，冠层高度/叶宽/叶投影/热点来自地类参数；球面叶倾角，暂无聚集指数和垂直廓线；
- HiStream 可解析三维结构，用于生成样本和校验 STREAM 的简化。

**处理原则**

1. 本轮反演目标只有 LST/LSCT，**植被结构作为输入/先验**，不作为主反演变量；
2. 结构误差必须传播到 LST/LSCT 的不确定性，不能当作真值；
3. 单靠 TIR 无法反演结构；若要与结构联合，必须引入光学 BRF/LAI、SAR/LiDAR 高度或多角度信息；
4. 可选的弱更新：只更新低维有效参数（如有效 LAI、聚集指数），并加先验/时间平滑，不逐像元放开全部结构参数；
5. 结构变化慢，按物候/季节更新，不与逐日温度同化同步。

**必须做的敏感性试验**

- LAI、冠层高度、叶倾角、聚集指数、热点对 BRF/BT/LST/LSCT 的影响；
- 结构误差导致的 LST/LSCT 偏差，是否超过产品精度目标；
- 用 HiStream 三维样本检验均匀冠层近似的偏差边界。

## 3.3 迭代反演与同化

**两条路线，不要混在一起**

| 路线 | 时间尺度 | 状态 | 方法 | 用途 |
| --- | --- | --- | --- | --- |
| 单景迭代反演 | 单次过境 | LST 或四组分温度 | 变分/Gauss–Newton，结构固定 | 单景 LST/LSCT 产品 |
| 时间序列同化 | 多时次/日循环 | LST/LSCT + 土壤温度/水分（可选结构） | EnKF/4D-Var，EB 作为时间模型 | 静止卫星/多时相产品，填补云缺 |

**观测**

- 极轨：Landsat、Sentinel-3 SLSTR（双视角）、MODIS；
- 静止：Himawari、FY-4（高频 LST，适合同化）；
- 光学：Sentinel-2/Landsat 提供 LAI/覆盖度/结构先验；
- 辅助：DEM、地类、ERA5、云/QA。

**观测算子**

STREAM 正向（RT/EB）→ 大气 → SRF/PSF → 亮温/反射率；STREAM-NET 可做前向残差修正；结构图作为算子输入。

**同化要点**

- 状态向量不要过大：LST/LSCT + 土壤温度/水分，结构只作为静态/慢变参数；
- 观测误差与模型误差分开；结构误差进入模型误差协方差；
- 云/雨剔除、时间插值、质量标记；
- 用 OSSE（HiStream 样本）先验证可识别性和同化增益，再上真实卫星。

## 4. 精度目标（建议，待验证）

| 产品 | 场景 | 目标 | 验证方式 |
| --- | --- | --- | --- |
| LST | 植被/农田/裸土（非城市） | RMSE ≤ 1.5 K，bias ≤ 0.5 K | 站点、UAV、跨传感器 |
| LST | 城市/异质像元 | RMSE ≤ 2.0 K | UAV、高分辨率航空 |
| LSCT 晴/阴土壤 | 多角度或有强先验 | RMSE ≤ 2.5 K | UAV 多角度、组分温度观测 |
| LSCT 晴/阴叶片 | 多角度或有强先验 | RMSE ≤ 3.0 K | UAV/站点、热像仪 |
| 不确定性 | 全部 | 68% 覆盖接近 1σ；QA 有效率 ≥ 95% 晴空 | 覆盖率、可靠性图 |

说明：LSCT 的单组分精度高度依赖观测角度数、波段数、先验和验证数据；以上是产品目标，不是当前原型已达标。

## 5. 算法需求

1. **单点核**：以 TiRT/TIRTEB 的验证结果为基准；STREAM 复用其公式/常量/参数，做影像级封装，不另起一套单点算法；
2. **LST 基线**：分裂窗（双波段）或单通道 + 大气校正；系数按传感器/大气条件，输入发射率与水汽，输出误差传播；STREAM 负责影像级实现、QA、批量与时序，不用可微反演；
3. **LSCT 反演**：正向 STREAM 像元级 RT/EB（hom3 节点辐射度 + Planck + 大气），可微；观测算子支持多角度、多波段、多时相；
4. **代价函数**：观测项 + 先验项 + 空间/时间平滑项；SW 的 LST 可作为等式约束或初值；
5. **优化**：Gauss–Newton/L-BFGS；EB 用隐式微分或弱约束；
6. **不确定性**：Laplace 近似或集合；输出逐像元 1σ；
7. **QA**：云、水、雪、饱和、非收敛、低置信度；
8. **收敛**：残差阈值、迭代上限、失败标记，不把未收敛结果当产品；
9. **可复现**：记录版本、参数、先验、发射率、大气、样本快照。

## 7. 接口与交付

- CLI：`stream invert --config invert.json`；配置文件包含观测、先验、发射率、大气、输出；
- Python API：与 `models/stream` 共用常量/光谱，便于科研用户批量与二次开发；
- 输出：GeoTIFF（LST/LSCT/不确定性/QA/组分比例）+ JSON 元数据 + 精度报告；
- 工作台：STREAM 工作台增加“反演”模式，选择 LST/LSCT，显示结果、不确定性、QA；
- 批量/时序：输入列表或时间范围，输出目录按场景组织。

## 8. MVP 验收标准

**LST MVP**
1. 输入一景 Landsat 8/9（B10/B11）+ 发射率 + 大气 + 云掩膜 + 地类；
2. 用**分裂窗/单通道基线**输出 LST、1σ、QA，GeoTIFF 与 JSON；
3. 与 UAV/站点或外部 LST 产品对比，给出 RMSE/bias/覆盖率；
4. 运行时间达到目标；失败像元有明确原因。

**LSCT MVP**
1. 输入多角度 TIR（如 SLSTR 双视角）或多时相 + LAI/覆盖度先验；
2. 输出四组分温度、组分比例、1σ、QA；
3. 用 UAV 多角度或 HiStream 样本做 OSSE，给出分地类精度；
4. 明确说明单角度单波段不提供 LSCT 产品。

## 9. 需要确认

1. 首个观测源：Landsat（单视角、2 波段）还是 Sentinel-3 SLSTR（双视角）或 UAV 多角度？
2. 发射率来源：NBEM/ASTER/JPL/固定值，谁提供？
3. 大气：外部大气校正产品，还是 STREAM 内接 MODTRAN LUT？
4. LSCT 的验证数据：是否有 UAV 多角度/组分温度观测，或先用 HiStream 样本做 OSSE？
5. LST 定义：方向性温度还是归一化到天底？产品给谁用、和哪家产品对比？
