# FacetRT 光谱 GPU 改造

在原有 GPU 可见性图与双面辐射求解基础上，FacetRT 的逐面元光学组装、受光／阴影辐射状态拆分、输出归一化、第一波段的直射增强量和加速路径的收敛判断现由 GPU 完成。几何、材质波段表、前一波段的物理辐射场及逐波段输出驻留显存，最后一次性读回输出数组。相邻波段初值不再下载到 CPU 后重新上传；光学与热红外类别切换时仍清零初值。

传统求解固定 64 轮；加速求解每 8 轮检查一次 `maxDelta <= 1e-4`，最多 64 轮。GPU 使用间接 dispatch 将已收敛波段的后续组数置零，保持原来每 8 轮的停止位置和迭代预算。此处的 GPU 收敛控制用于新的光谱路径；保留的通用 `solveAccelerated` 参考接口仍按原方式读取批次残差，也已补齐 GPU 入射辐射汇总。

CPU 保留 OBJ 与纹理读取、光谱材质模型求值，以及每材质／波段一次的双精度黑体辐亮度计算；GPU 将这些材质性质组装到每个面元。材质温度固定时，不能把同一黑体计算重复到每个面元。JSON 输出改用 `std::to_chars` 与 64 KiB 分块写入，保留原来的 9 位有效数字，避免数千万次带 locale 的逐值流格式化。JSON／TIFF／PNG 写盘及服务器的相机光栅化仍由 CPU 完成，本次没有迁移相机图像光栅化。

环境变量 `HISTREAM_FACET_SPECTRAL_BACKEND=cpu` 可使用保留的 CPU 光学组装／输出处理路径，辐射仍在 GPU。默认使用新的 GPU 光谱路径。`HISTREAM_FACET_VALIDATE_SPECTRAL=1` 在相同可见性图、受光比例及上一物理波段初值上执行保留路径的对照，核对光学参数、辐射场、受光／阴影状态、归一化输出与迭代次数；参考状态不替换 GPU 输出。审计期间额外 CPU 工作及读回不计入性能测试。

原生 `facetrt.json` 的 `execution` 记录实际后端，`spectralVerification` 记录检查结果；检查关闭时状态为 `not_run`。相同几何的可见性图仍跨波段复用，原光栅采样算法不变。

构建需要同时完成 `histream` 和 `histream_runtime_resources`，部署 `shader/facetrt/spectral.comp.spv`。与 FacetEB 共用的迭代函数调整后，需重新检查 FacetEB；此次 SCOPE 1.73 单日与 SCOPE 2 的 30 场景结果位于独立目录 `.test/facetrt-gpu-20261013/final/`，全部 FacetEB 节点重新运行；未改动的 VoxelEB 使用本日已经通过的独立产物共同评分，不重新生成。

## 性能边界

2026-10-13，同一 34,322 面元玉米场景、RTX PRO 6000 Blackwell。3 波段为 550/850/10500 nm；84 波段包括 400–2400 nm 的 25 nm 间隔光学波段及 8500/10500/12500 nm。FacetRT 为固定照明和给定材质温度的静态求解，此处不是 48 节点能量平衡。

最终构建复测（关闭 CPU 对照，见 `gpu-summary.json`）：

| 84 波段路径 | 改造前总耗时 | 改造后总耗时 | 改造前辐射求解 | 改造后辐射求解 |
|---|---:|---:|---:|---:|
| 传统 | 12.27 s | 7.22 s | 1.78 s | 1.67 s |
| 加速 | 11.21 s | 6.24 s | 0.64 s | 0.65 s |

总耗时含进程启动、初始化和原生 JSON 输出（84 波段约 231 MB），不含相机图像导出。收益主要来自输出序列化，现有场景的辐射求解已经主要在 GPU，因此此次 GPU 模块迁移未显著缩短加速路径的辐射求解时间。不能将总流程的约 1.7–1.8 倍改善表述为辐射内核同等提速。3 波段输出较小，启动成本占主导，总耗时变化更小。

最终 3／84 波段对照（传统及加速路径）均通过，光学参数、原始辐射场、受光／阴影状态最大差异为 0，归一化输出最大差异为 `5.96046448e-8`，每波段迭代次数差异为 0。另有单波段、连续热红外波段、先热红外后光学及交替类别共 10 项检查，全部通过。该一致性是在同一次运行的相同可见性图和受光比例上核对，不能把原光栅采样跨运行的随机差异混入 GPU 迁移误差。

通用的单波段、波段类别切换及热红外相邻波段初值检查：

```powershell
node validation/facetrt-gpu/run.mjs <project.json绝对路径> <新的检查输出目录>
```

此处仅验证与原有实现的一致性，不能视为真实场景辐射精度验证。性能实测与检查摘要见本次目录中的 `baseline-summary.json`、`gpu-summary.json`、`audit-summary.json` 和 `final-status.log`。
