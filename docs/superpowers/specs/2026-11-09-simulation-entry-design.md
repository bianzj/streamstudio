# 现有模拟功能的统一入口

用户要求将已有工作整理进代码，并说明当前功能。沿用现有原生模块、FacetEB和正式Python工具，不改动物理公式、旧入口或冻结案例。

本轮选择功能注册表加可执行任务入口：注册表同时说明实现位置、CPU/GPU、启用方式、检查和限制；任务入口解析相对路径，检查输入，依次执行已有工具，保存日志与来源记录。支持原生场景和小镇热耦合两条现有运行链。仅写说明不能解决入口分散；全面移植到新原生模块会扩大本次整理范围，既有六项归并计划继续单独保留。

接口为`run_case.py features [--json]`、`run_case.py check JOB`、`run_case.py run JOB`。JOB仅接受显式schemaVersion=1及各运行链支持的字段。所有路径相对JOB解析；程序和编码器显式指定。check只读且不调用引擎；run仅接受全新输出目录，先完成文件检查，再创建根目录并将实际结果写入result/。run.json保存输入、引擎、shader及工具哈希、实际命令、步骤状态和错误。输入在执行前、各步之间与结束后重新核对。

功能清单不等于某次运行全部启用；实际启用选项与科学收敛仍由原生结果/耦合诊断决定。预设破口、火焰外观、单波长IR、3–5μm积分、静态RGB参考和原生动态RGB必须区分。不能宣称已完成结构破坏、真实燃烧、大气光谱传播或全流程GPU。

检查覆盖：相对路径、未知字段、重复输出、资产哈希、输入变化、进程失败、零退出但缺少有效结果、目录包含输入、只读计划，以及一次小网格真实原生运行。只运行相关轻量检查，不重算已封存小镇。
