# 光伏玉米几何示例

打开 project.json，选择面元能量平衡（FacetEB）运行。前 48 节点为预热，后 48 节点为分析日。光伏参数位于物化材质 pv_solid，光谱位于 pv_flat。不是实际平铺组件阵列，采用玉米曲面几何。

已验证的原生运行（2026-09-10）：96 节点；第二天直流电量 11.9796 kWh，峰值功率 1237.31 W，最高面积平均板温 37.5831℃，最大热平衡残差 0.04667 W/m²。交换图有 1488440 条有向边，无片元或哈希溢出。方向/空间离散收敛仍需按实际项目检验。

在“分析 → 三维分析”中选择光伏热电耦合时刻；完整数值见 output/photovoltaic_summary.csv。模型假设与结果单位见 ../../../docs/photovoltaic.md（仓库 docs/photovoltaic.md）。
