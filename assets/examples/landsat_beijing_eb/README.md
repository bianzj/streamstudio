# 北京市 Landsat 300 m · ERA5能量平衡

分类：区域遥感影像。层级：项目内置精选。

## 打开

在 StreamStudio 的“打开示例”中选择本案例，指定保存目录。程序会复制案例后打开，运行结果写入副本的 output/。也可在遥感影像模拟工作台打开 project.json。inputs/ 与 era5/ 均随案例提供，运行不依赖作者电脑的其他盘符。

## 参考结果

请求时刻：2019-08-15T02:55:00Z。2026-10-31参考运行：180326/180408个EB像元综合收敛（99.95%），82个未收敛；水体1774个另行处理。

reference/ 保留反射率、组分温度、亮温、辐射等效地表温度、诊断摘要和异常清单。convergence_mask.tif：0=未参与EB求解；1=综合收敛；2=未收敛。EB统计应使用质量标记。参考文件是历史执行结果，不是打开案例后新生成的结果。完整通量和运行过程记录保存在项目外部扩展案例。

## 适用边界

数值收敛只覆盖请求过境时刻，不等同于独立实测精度。输入、参数和收敛阈值没有为此打包而修改；energy参数已显式固定为本次参考运行的配置。ERA5缺地表位势，高程订正未实际执行。摘要中的稳定度说明存在旧文字，以记录的引擎哈希及实际诊断标记为准。

## 数据来源

地类由2019 GLC_FCS30D映射到IGBP；DEM为FABDEM；LAI为Landsat 30m产品。300m输入由30m网格聚合，聚合不提高原始数据精度。ERA5气象日期为2019-08-15。保留数据来源说明；软件许可证不代替输入数据各自的再分发条款。
