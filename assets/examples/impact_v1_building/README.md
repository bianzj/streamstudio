# 建筑撞击 · impact-v1（场景动画研究功能）

**经验模型估算，未经独立验证。** 本例用通用示例参数演示 HiStream 场景动画的 `impact-v1` 经验撞击事件模型，不对应任何具体弹药、目标或实测事件，结果不能用于毁伤评估、武器效应或安全评价。

## 运行

场景动画的界面入口当前隐藏（`SCENE_ANIMATION_UI_ENABLED=false`），本示例不会出现在“项目 → 打开示例…”列表中，请用命令行运行下面的 `sequence.json`。入口恢复后可从“项目 → 打开示例… → 建筑撞击 · impact-v1”打开：示例复制到所选目录，面板自动填入副本中的输入，输出写入副本的 `output/`。

命令行：`histream.exe eSceneAnimation sequence.json 新输出目录`（输出目录必须不存在）。

规模：1280×720，288 帧，24 fps，红外 + 可见光，主相机 `flight_side` 加附加相机 `street`（`cameras/street/`）。开发机 RTX PRO 6000 上约 110 秒；较弱的显卡可能需要十几分钟，可先把 `sequence.lastFrame` 改小试运行。需要硬件 GPU 和带场景动画模块的引擎（当前开发版；2.0.1 安装包的引擎不含该模块）。

## 参数（`sequence.impactPhysics`，通用示例值）

| 项 | 值 |
|---|---|
| 弹体 | 250 kg，直径 0.34 m，长 3 m，340 m/s，头部系数 N = 0.85，无动力 |
| 装药 | 100 kg TNT 当量 |
| 引信 | 接触后延时 5 ms |
| 墙体 | 混凝土 0.3 m，Young S = 0.9，临界冲量 2000 Pa·s，密度 2300 kg/m³ |
| 碎块 | 小于 2 kg 或 0.05 m 记为粉碎 |
| 能量分配 | 冲击波 0.6，进入空气的热量 0.3 |
| 呈现 | `presentationTimeScale` = 0.2：每秒视频对应 0.2 物理秒（5 倍慢放），12 秒视频对应 2.4 秒物理时间 |

340 m/s 使半无限穿深（1.10 m）大于 3 倍弹径，处于 Young 公式的适用范围内。

## 本例的计算结果（2026-11-12，开发机）

- 首次接触 0.093 s，墙体被穿透（出口速度约 272 m/s），起爆 0.098 s，起爆点在外墙后约 1.1 m；
- 178 个预设碎块中 126 个失效（30 个粉碎、96 个作为刚体碎片按冲击波到达时刻释放），52 个保持完好；
- 碎片总动能 31.8 MJ，最大速度 132 m/s，低于冲击波能量份额；
- 火球直径 16.8 m、持续 1.31 s；注入空气的热量 126 MJ，烟尘 674 kg；
- 运行清单无警告，热量闭合比例 0.67（一个 1/60 s 输运步内，含扩散、辐射、边界损失和进入固体单元的部分）。

完整数值见运行目录的 `event.json`（每个碎块的距离、反射冲量、失效原因与速度）和 `run-manifest.json`。

## 文件

- `sequence.json`：场景动画输入，所有路径相对本文件夹，每个文件带 SHA256；
- `asset_*.obj`：建筑与街区；`sequence_*.obj/json`：预设破口剩余体、碎块及其连接；
- `background/`：FacetEB 背景温度场及其来源文件（引擎按哈希核对，请勿修改）。
