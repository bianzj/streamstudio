# Physical reflectance-variance textures

These seamless BaseColor images are used only as spatial variance templates.
HiStream converts sRGB to linear luminance, removes the image mean, samples the
result with world-space triplanar projection, and area-normalizes every material
to a factor mean of exactly 1.0. The configured spectral reflectance remains the
material mean; thermal-infrared emissivity is not changed.

Physical textures are disabled by default. `strength` caps the contrast (the
image deviation is first divided by its maximum, so the resulting coefficient
of variation is typically only a quarter of `strength`). `relativeStd` > 0
instead sets the area-weighted coefficient of variation directly (e.g. 0.10 =
10 %); the image then only defines the pattern and its scale. Both are capped so
reflectance stays positive and below 1 - transmittance; the engine log reports
the achieved `cv`. `repeatSize` is the world-space tile size in metres. Each
facet samples the texture once at its centroid, so the mesh must be finer than
the texture patches. A textured background spectrum makes RayTracing tessellate
flat ground at the voxel size. Users can also import their own PNG/JPG/TIF; it
is copied to the project's `textures/` folder. FacetRT, FacetEB and RayTracing
apply the same per-triangle factors; voxel modes ignore physical textures.

The concrete, brick, asphalt and metal images are ambientCG CC0 assets. The
canvas-weave, woodland/desert/digital camouflage, awning-stripe, crumpled-film,
sand-mottling and soil-mottling images are generated by
`tools/generate-tarp-assets.py`. See `LICENSE.md` and `catalog.json`.

`class_*.png` are lossless class maps for spectral class textures (each colour
is bound to a spectrum) and `openness_*.png` are grey maps for openness
textures (black = minimum, white = maximum openness). They are applied when a
run is staged (`tools/surface-textures.mjs`) and must stay PNG: JPEG blurs class
colours.
