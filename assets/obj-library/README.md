# OBJ 资源分类

- `building/`：建筑
- `solar/`：单块、地面阵列、屋顶阵列和垂直双面太阳能板
- `vegetation/`：乔木、灌木和草本
- `crop/`：玉米、小麦、水稻和向日葵；玉米、小麦各含 4 个生长阶段
- `vehicle/`：轿车、SUV、公交车、货车、应急车辆和农业车辆
- `ship/`：现代集装箱船、散货船、邮轮和简易巡逻艇
- `aircraft/`：轻型飞机、喷气客机、涡桨运输机和直升机
- `special_vehicle/`：轻型、中型、重型坦克及其他特种车辆
- `terrain/`：岩石等地表构件
- `large_scene/`：大范围城市、研究区模型和 100 m 混交森林示例

界面中使用原有“场景对象 → 导入 OBJ 实体”，从对应目录选择文件。车辆、船舶和植被优先从各自的 `typical/` 目录选择；每类保留一个标记为“简易”的快速占位模型。完整分级见 `ASSET_AUDIT.md` 和 `catalog.json` 的 `defaultSets`。

作物和标注“简易”的模型适合大数量实例分布；典型模型兼顾真实结构和体元化效率。历史帆船、卡通车辆及小型卡通船已经从资产库移除。
