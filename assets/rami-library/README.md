# RAMI 基准场景

`HET07_JPS_SUM/` 是 RAMI-V 的 Järvselja Pine Stand 夏季真实森林场景，来源于 DART 团队公开提供的 Wavefront OBJ 转写包。

- 场景范围：105.932 m × 106.118 m × 18.56 m
- 实例数量：1120
- OBJ 已从 RAMI 的 Z-up 转为 Stream Studio 的 Y-up
- `positions/*.txt` 使用 `X Y Z scale rotation`，可直接作为对象分布文件导入
- `metadata/` 保留官方场景、光谱和照明说明
- 官方场景：https://rami-benchmark.jrc.ec.europa.eu/
- DART OBJ 下载：https://dart.omp.eu/index.php#/doc
